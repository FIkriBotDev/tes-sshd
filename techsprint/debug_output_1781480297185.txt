Setelah itu masuk ke manajemen file: mkdir (Make Directory) untuk membuat direktori baru; contoh mkdir new_folder membuat folder new_folder di folder aktif. rm (Remove) digunakan untuk menghapus file atau direktori; contoh rm my_file.txt menghapus file bernama my_file.txt di working directory. touch dipakai untuk membuat file baru yang kosong; contohnya touch new_file.txt akan membuat file kosong tersebut. Untuk operasi salin dan pindah: cp (Copy) menyalin file/direktori dari lokasi sumber ke tujuan; contohnya cp source_file.txt destinationfolder/ menyalin source_file.txt ke destinationfolder. mv (Move) digunakan untuk memindahkan atau merename; contoh mv oldname.txt newname.txt merename oldname.txt menjadi newname.txt (dan bisa juga digunakan untuk memindahkan). Untuk melihat isi file: cat (Concatenate) menampilkan content file, menggabungkan file, dan juga dapat melakukan redirect output; contoh cat file.txt menampilkan isi file.txt. less (Less, tanpa singkatan) berguna untuk viewing file tanpa harus membukanya sepenuhnya; khususnya saat file besar agar bisa scroll dengan nyaman. head (Head) mengeluarkan bagian awal file; contoh head file.txt menampilkan 10 baris pertama. tail (Tail) mengeluarkan bagian akhir file; contoh tail file.txt menampilkan 10 baris terakhir. Selanjutnya bagian pencarian: grep (Global Regular Expression Print) mencari baris dalam file yang cocok dengan pattern tertentu; contoh grep 'hello' file.txt menampilkan baris yang mengandung kata 'hello'. find (Find) mencari file/direktori berdasarkan kondisi pada struktur folder; contoh find /home -name my_file.txt akan menemukan my_file.txt di direktori /home dan subdirektorinya. Lalu ada man (Manual) yang menampilkan user manual dari command yang dapat dijalankan; contoh man ls menampilkan manual untuk ls. Ada juga sudo (SuperUser Do) yang dipakai untuk menjalankan perintah yang membutuhkan hak admin atau root permission; contoh sudo apt-get update memperbarui daftar paket tanpa benar-benar menginstal/upgrade. Setelah itu bagian monitoring sistem dan proses: df (Disk Filesystem) menampilkan penggunaan disk: space terpakai dan tersedia; contoh df -h menampilkan dalam format human-readable. du (Disk Usage) mengestimasi pemakaian space untuk file/direktori; contoh du -sh /home/user/* menampilkan ukuran masing-masing file/direktori secara ringkas dan human-readable. ps (Process Status) memberi informasi proses yang sedang berjalan termasuk PID; contoh ps -aux menampilkan semua proses yang running. top (Table of Processes) adalah view real-time proses; kamu cukup mengetik top untuk melihat proses berjalan secara langsung. kill (Kill, tanpa singkatan) menghentikan proses manual; contoh kill 12345 menghentikan proses dengan PID 12345. Berikutnya bagian archive dan permission: tar (Tape Archive) membuat dan mengekstrak archive .tar atau .tar.gz. Contoh tar -cvf archive.tar /home/user membuat archive tar dari /home/user. chmod (Change Mode) mengubah permissions file/dir; contoh chmod 755 my_file.txt mengatur read/write/execute untuk owner dan read/execute untuk group dan others sesuai standar 755. chown (Change Owner) mengubah owner dan group; contoh chown username:groupname my_file.txt mengubah owner jadi username dan groupname. Bagian networking: ssh (Secure Shell) untuk login ke mesin remote dan bekerja langsung di sana; contoh ssh username@remote_host login sebagai username pada remote_host. wget (World Wide Web Get) untuk download non-interaktif file dari web; contoh wget https://example.com/file.zip mengunduh file.zip ke current directory. curl (Client URL) untuk transfer data dari command line atau script; mendukung banyak protokol seperti HTTP/HTTPS/FTP dan juga SCP/SFTP; contoh curl -O https://example.com/file.zip mengunduh file.zip ke current directory. Terakhir command shell yang ringan: alias membuat shortcut untuk command lain; contoh alias l='ls -l' membuat l menjalankan ls -l. echo (Echo) menampilkan teks/string ke standard output atau file; contoh echo "Hello World" menampilkan teks itu di terminal. exit (Exit) digunakan untuk keluar dari shell yang sedang berjalan; bisa menerima argumen N dan keluar dengan status N, contoh exit akan keluar sederhana, sedangkan exit 1 keluar dengan status error umum (unspecified error). Untuk tutor, tekankan perbedaan fungsi tiap command: (1) ls/pwd/cd untuk navigasi, (2) mkdir/touch/rm untuk pembuatan dan penghapusan, (3) cp/mv untuk copy vs move/rename, (4) cat/less/head/tail untuk membaca file dengan gaya berbeda, (5) grep (isi) vs find (lokasi), (6) man untuk dokumentasi dan sudo untuk privilege, (7) df/du/ps/top/kill untuk melihat dan mengelola sistem/proses, (8) tar/ chmod/ chown untuk archive dan control keamanan, (9) ssh/wget/curl untuk akses dan download dari jaringan, serta (10) alias/echo/exit untuk kenyamanan dan kontrol shell. Tutor juga harus menekankan bahwa contoh pada materi merupakan pola umum, dan siswa sebaiknya mencoba variasi parameter sambil memahami dampaknya (terutama rm, chmod, chown, dan sudo)."
