Chapter 1: Networking Fundamental: IP Addressing, CIDR, dan Subnetting

Jaringan komputer menghubungkan sejumlah komputer agar dapat berkomunikasi satu sama lain. Komunikasi terjadi melalui pertukaran data antara pengirim dan penerima, dan agar pesan sampai ke pihak yang sesuai, proses pengiriman memerlukan alamat. Alamat yang digunakan pada jaringan komputer disebut IP Address.

Pengalamatan yang umum dipakai saat ini adalah IPv4. IPv4 terdiri dari 4 byte yang dipisahkan oleh titik, dan tiap byte memiliki nilai hingga 255 (secara teori jumlah kemungkinan alamat adalah 255 x 255 x 255 x 255). IP Address terdiri dari dua bagian, yaitu network address untuk mendefinisikan alamat jaringan dan host identifier untuk mendefinisikan host di dalam jaringan tersebut. Host pada network address yang sama dapat berkomunikasi langsung, sedangkan host dengan network address berbeda memerlukan router untuk berkomunikasi.

Pada awal implementasi, IPv4 menggunakan pembagian berdasarkan class, tetapi seiring perkembangan jaringan dan internet, metode class menjadi kurang relevan. Saat ini yang umum digunakan adalah CIDR (Classless). CIDR memakai notasi /slash diikuti angka desimal (0–24) untuk menyatakan panjang subnet mask. Contoh 192.168.100.14/24 berarti subnet mask 255.255.255.0, sehingga network address menjadi 192.168.100.0. CIDR membantu menentukan batas network dan host dengan lebih fleksibel.

Pada kasus tertentu, satu alamat network perlu dibagi menjadi beberapa network kecil. Proses memecah network menjadi beberapa network disebut subnetting. Tujuan subnetting antara lain: efisiensi penggunaan IP, mengurangi kepadatan traffic, dan memudahkan pengelolaan jaringan. Metode pembentukan subnet yang umum digunakan adalah VLSM (Variable Length Subnet Mask), yaitu proses dimulai dari pendefinisian jumlah host per subnet, lalu menentukan subnet mask agar subnetwork address terbentuk sesuai kebutuhan.

Chapter 2: Routing: Konsep Router dan Routing Table (Static/Dinamis)

Host yang berada pada network address dan subnet mask yang sama dapat berkomunikasi langsung. Namun, untuk berkomunikasi dengan jaringan yang berbeda diperlukan jalur yang mengarahkan paket ke tujuan. Proses penentuan jalur ini disebut routing, dan dilakukan pada device bernama router.

Router bertugas menyediakan jalur komunikasi menuju jaringan lain. Untuk menentukan jalur yang dapat dilalui, router menggunakan tabel yang berisi daftar rute menuju jaringan tertentu. Tabel tersebut disebut routing table. Pengisian routing table dapat dilakukan secara manual (static) oleh administrator atau dinamis menggunakan algoritma tertentu.

Untuk mengisi routing table diperlukan informasi penting, seperti alamat network tujuan, alamat router yang menangani jaringan tujuan, serta alamat router tetangga yang dapat dilalui untuk mencapai network tujuan. Dengan demikian, setiap router memiliki routing table sendiri untuk mendefinisikan jalur yang akan digunakan saat paket dikirim ke jaringan lain.

Gambaran umum routing adalah router menghubungkan jaringan-jaringan yang berbeda dengan memanfaatkan informasi dalam routing table. Ketika sebuah host mengirim data ke network yang berbeda, router akan membaca routing table untuk memilih next-hop atau jalur yang tepat agar paket mencapai tujuan.

Chapter 3: Mikrotik RouterOS Fundamental: Winbox, Konfigurasi IP Static, DHCP Server, dan Routing Static

Mikrotik RouterOS adalah sistem operasi khusus untuk memanajemen network. Kata Mikrotik merujuk pada bahasa Latvia yang berarti network kecil, dan memiliki visi untuk memudahkan manajemen networking. RouterOS menawarkan kemudahan implementasi, konfigurasi, serta integrasi dengan perangkat lain.

Mikrotik tersedia dalam dua jenis: Mikrotik RouterOS (ROS) dan Mikrotik RouterBOARD. RouterBOARD adalah hardware spesifik yang sudah tertanam sistem operasi Mikrotik untuk dijadikan router. Sementara itu, RouterOS adalah sistem operasi yang dapat diinstall pada PC agar PC tersebut dapat berfungsi sebagai router, bridge, firewall, pengaturan bandwidth, wireless AP/client, dan fungsi lainnya.

Untuk memudahkan manajemen, Mikrotik menyediakan tools, yang umum digunakan adalah Winbox. Winbox berbasis GUI untuk Windows, menyediakan kemudahan dan shortcut agar admin dapat melakukan konfigurasi perangkat Mikrotik secara efektif.

Konfigurasi IP Address Static dilakukan melalui Winbox: (1) buka winbox.exe, (2) masukkan IP MikroTik pada kolom Connect To, masukkan username dan password, lalu klik Connect, (3) pada menu kiri klik IP, kemudian pilih Addresses untuk membuat IP Address static, (4) klik tombol tanda + untuk menambah address, lalu isi kolom Address, Network (jika perlu), dan Interface. Terakhir klik Apply lalu OK. Setelah itu IP akan muncul di Address List.

Konfigurasi DHCP pada Mikrotik: DHCP Server berfungsi memberikan layanan IP Address otomatis bagi client yang diset automatic. DHCP server secara otomatis menyediakan informasi seperti IP Address, IP Gateway, dan IP DNS Server. Secara praktik, ada dua langkah utama: membuat IP Pool (range IP yang akan dipakai), lalu membuat DHCP Server dan menambahkan network yang akan diberikan.

Langkah membuat IP Pool: (1) hubungkan Winbox ke Mikrotik, lalu klik IP kemudian Pool, (2) klik tombol + untuk membuat New IP Pool, isi Name dan Addresses (contoh: 172.16.162.30-172.16.162.40), kemudian klik Apply dan OK. Setelah pool muncul, lanjut ke konfigurasi DHCP Server: klik IP lalu DHCP Server, klik tombol + untuk New DHCP Server, isi Name, pilih Interface (yang terhubung ke local), dan pilih Address Pool yang dibuat. Klik Apply lalu OK. Setelah DHCP server dibuat, pada tab Networks klik + untuk membuat DHCP Network dengan mengisi Address, Gateway, Netmask, dan DNS Server, lalu Apply dan OK.

Untuk pengujian, gunakan komputer client agar mendapatkan IP dari DHCP. Jika IP yang diterima sesuai konfigurasi DHCP, berarti konfigurasi benar. Lanjutkan dengan pengujian koneksi melalui ping dari client menuju IP MikroTik; bila Mikrotik membalas ping dari client, maka IP dinamis dan konektivitas dasar sudah berjalan.

Routing Static pada Mikrotik merupakan routing dengan routing table yang diatur manual oleh administrator jaringan. Static routing adalah pengaturan routing paling sederhana pada jaringan komputer. Tahapannya pada modul mengarah pada bagaimana menentukan jalur menuju network tujuan dengan mencatat rute secara manual ke routing table agar paket dapat diarahkan ke jaringan yang berbeda.
