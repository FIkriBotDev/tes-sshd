Materi utama:
Materi ini memperkenalkan Artificial Intelligence (AI) sebagai teknologi yang memungkinkan komputer menjalankan tugas yang biasanya membutuhkan kecerdasan manusia. AI mempelajari pola dari data dalam jumlah besar untuk menghasilkan prediksi atau jawaban. Penerapannya terlihat pada chatbot, image recognition, voice assistant, recommendation system, hingga AI generator, serta digunakan di pendidikan, kesehatan, bisnis, keamanan siber, dan media sosial.

Selain pengenalan AI, materi juga membahas dasar pemrograman Python. Python dipilih karena sintaksnya sederhana dan mudah dipelajari, serta sering dipakai untuk web development, data science, cybersecurity, AI & Machine Learning, dan automasi. Materi mencakup konsep variabel dan tipe data, lalu dilanjutkan dengan percabangan (if-else) dan perulangan (for/while) untuk membangun logika program.

Terakhir, materi menjelaskan konsep dasar Machine Learning sebagai cabang AI. Machine Learning terbagi menjadi supervised learning, unsupervised learning, dan reinforcement learning, dengan dataset sebagai komponen krusial. Materi ditutup dengan gambaran masa depan AI beserta tantangan seperti privasi data, penyalahgunaan, deepfake, dan etika penggunaan, sehingga developer AI perlu memahami teknologi dan tanggung jawab penggunaannya.

Materi ini membahas dasar-dasar AI dan pemrograman Python untuk membentuk landasan berpikir komputasional sekaligus fondasi konsep Machine Learning. Dimulai dari pengertian AI: Artificial Intelligence adalah teknologi yang memungkinkan komputer mengerjakan tugas yang biasanya memerlukan kecerdasan manusia. Penjelasan menekankan bahwa AI tidak sekadar menjalankan instruksi statis, tetapi mempelajari data sehingga mampu menghasilkan prediksi atau jawaban. Materi memberikan contoh nyata seperti chatbot (ChatGPT dan Gemini), image recognition (pengenalan wajah pada smartphone), voice assistant, dan recommendation system (contoh rekomendasi video YouTube). Ada juga contoh sistem yang memanfaatkan AI untuk kebutuhan praktis seperti filter spam email. Pada bagian ini, AI juga dikaitkan dengan banyak bidang penerapan: pendidikan, kesehatan, bisnis, keamanan siber, dan media sosial. Selain itu, untuk kendaraan modern seperti mobil self-driving, materi menyoroti bahwa AI umumnya memanfaatkan Machine Learning dan Deep Learning.

Setelah pengantar AI, materi berpindah ke dasar pemrograman Python. Python dijelaskan sebagai bahasa pemrograman yang populer karena sintaksnya sederhana dan mudah dipelajari. Materi menekankan relevansi Python dengan kebutuhan industri dan riset: Python sering digunakan untuk web development, data science, cybersecurity, AI & Machine Learning, serta automation. Tutor sebaiknya membantu peserta memahami bahwa Python menjadi alat untuk menulis program yang kemudian bisa digunakan untuk eksperimen data maupun membangun sistem berbasis AI.

Materi memperkenalkan contoh kode Python paling dasar, yaitu print("Hello World") untuk menampilkan output. Peserta juga perlu memahami konsep variabel: variabel adalah tempat menyimpan data agar bisa dipakai di bagian lain program. Contoh yang diberikan adalah nama = "Fikri" dan umur = 18. Berikutnya adalah tipe data dasar Python yang disebutkan: String (teks), Integer (bilangan bulat), Float (bilangan desimal), Boolean (True/False), dan List (kumpulan data). Tutor dapat menekankan bahwa pemahaman tipe data penting karena banyak operasi dan logika program bergantung pada jenis data yang diproses.

Materi kemudian membahas percabangan dan perulangan sebagai fondasi logika program. Percabangan digunakan untuk membuat keputusan berdasarkan kondisi. Contoh if-else pada materi menjelaskan skenario nilai ujian: jika nilai >= 75 maka output “Lulus”, jika tidak maka “Tidak Lulus”. Ini mengajarkan bahwa program dapat memiliki alur eksekusi berbeda tergantung input. Perulangan adalah mekanisme untuk menjalankan blok kode berulang. Materi memberi dua bentuk utama: for loop dan while loop. For loop ditunjukkan melalui for i in range(5): print(i) yang mencetak nilai dari rentang tertentu. Sedangkan while loop menggunakan kondisi yang dicek sebelum setiap iterasi: x = 0 lalu while x < 5: print(x) dan update x += 1 agar perulangan berhenti saat kondisi tidak terpenuhi lagi. Tutor dapat menekankan bahwa kunci while loop adalah pembaruan variabel agar tidak terjadi infinite loop.

Bagian selanjutnya mengarah ke dasar Machine Learning sebagai cabang AI. Machine Learning didefinisikan sebagai kemampuan komputer untuk belajar dari data. Materi menyinggung bahwa Machine Learning terbagi menjadi tiga kategori besar: Supervised Learning, Unsupervised Learning, dan Reinforcement Learning. Walaupun tidak dijelaskan detail algoritma, materi memberikan contoh kegunaan praktis: prediksi harga rumah, deteksi spam, analisis wajah, dan prediksi cuaca. Dalam konteks pembelajaran model, materi menekankan bahwa dataset sangat penting: kualitas data berpengaruh langsung pada hasil model AI. Tutor dapat mengaitkan konsep ini dengan pengalaman pemrograman: jika data input buruk atau tidak representatif, maka output model juga cenderung buruk.

Terakhir, materi membahas masa depan AI dan teknologi. AI diprediksi akan terus berkembang, dan banyak perusahaan menggunakan AI untuk meningkatkan produktivitas serta efisiensi. Namun materi juga menyoroti tantangan serius: privasi data, penyalahgunaan AI, deepfake, dan etika AI. Dengan demikian, materi menekankan bahwa seorang developer AI tidak hanya perlu menguasai teknologi, tetapi juga memahami batasan dan dampak etis dari penerapan AI. Kesimpulan menegaskan bahwa AI dan Python adalah kombinasi penting untuk dipelajari di era digital modern: Python sebagai alat untuk membangun dan mengolah logika, sedangkan AI/Machine Learning sebagai domain untuk mengubah data menjadi keputusan atau prediksi.
