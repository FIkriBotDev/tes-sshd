Materi course ini:
Kamu akan belajar cara mengakses FTP server menggunakan FileZilla dari langkah persiapan (scanning port dengan Nmap) sampai pengetesan membuat folder dan mengirim file. Materi ini fokus ke alur yang rapi dan praktis biar kamu bisa langsung coba sendiri.

Materi ini membahas cara mengakses FTP server menggunakan aplikasi FileZilla, dimulai dari tahap pengecekan konektivitas dan layanan yang berjalan di server. Konteks yang digunakan adalah sebuah IP server 10.1.2.5. Karena FTP adalah layanan jaringan yang berjalan pada port tertentu, langkah awal yang dilakukan adalah scanning port menggunakan Nmap. Pada langkah pertama, peserta diminta menjalankan perintah Nmap: nmap -sC -sV 10.1.2.5. Penjelasan logis yang perlu dipahami tutor: opsi -sC (default scripts) menjalankan kumpulan script bawaan yang membantu mendeteksi informasi tambahan, sedangkan -sV (service/version detection) mendeteksi layanan dan versi yang berjalan. Setelah perintah dijalankan, peserta harus membaca hasil scan dan memastikan bahwa port FTP (21/tcp) terbuka. Materi menyebutkan bahwa hasil scan menampilkan port 21/tcp terbuka dengan opsi Anonymous login. Ini adalah kunci untuk tahap berikutnya: jika server mengizinkan anonymous login, maka kamu bisa mengakses FTP tanpa akun khusus. Tutor sebaiknya menekankan bahwa jika port 21 tidak terbuka atau anonymous tidak diizinkan, maka proses koneksi menggunakan username Anonymous akan gagal atau tidak mendapat izin yang diperlukan.

Tahap kedua adalah mengakses FTP server menggunakan FileZilla. Tutor harus menjelaskan alur UI FileZilla secara friendly: buka aplikasi FileZilla, lalu isi kolom Host/IP dengan 10.1.2.5, isi User dengan “Anonymous”, biarkan kolom Password kosong (sesuai materi), dan isi Port dengan 21. Setelah itu klik tombol Quickconnect. Dari sini, peserta diharapkan berhasil terhubung ke server. Tutor juga dapat mengingatkan dua panel yang biasanya terlihat di FileZilla: panel kiri adalah local (folder/file di komputer pengguna) dan panel kanan adalah remote/server (isi di FTP server). Perbedaan panel ini penting karena semua operasi seperti upload dan pembuatan folder dilakukan berdasarkan lokasi panel.

Tahap ketiga adalah pengetesan membuat folder baru di FTP server. Tutor perlu membimbing peserta setelah terhubung, memilih direktori tujuan di panel server (kanan). Lalu klik kanan pada direktori tersebut dan pilih “Create Directory”. Setelah itu, masukkan nama folder, misalnya “test”. Pastikan tutor menekankan bahwa operasi ini terjadi di sisi server, jadi harus dilakukan di panel yang benar (server). Jika server mengizinkan write permission untuk anonymous, maka folder akan muncul di sisi remote.

Tahap keempat adalah pengetesan mengirim file. Tutor menjelaskan bahwa untuk upload file, peserta cukup melakukan drag and drop dari panel local (kiri) menuju panel server (kanan). Peserta menyeret file dari komputer mereka ke direktori remote yang sesuai (misalnya folder test bila ingin menguji ke dalam folder tersebut). Proses upload biasanya akan menunjukkan progress bar/riwayat transfer. Tutor perlu menekankan agar peserta menunggu sampai proses pengiriman file selesai sebelum menganggap upload berhasil. Setelah file terkirim, file tersebut akan muncul di panel remote/server.

Penutup materi menyatakan bahwa melalui langkah-langkah di atas, peserta telah berhasil mengakses FTP server menggunakan FileZilla, membuat folder baru, dan mengirim file ke server. Untuk tutor, poin penting yang harus ditegaskan adalah: (1) koneksi FTP dimulai dari pengecekan port 21 yang terbuka menggunakan Nmap, (2) login menggunakan “Anonymous” tanpa password karena server mengizinkan itu, (3) di FileZilla kamu bisa membuat folder dan mengunggah file dengan memanfaatkan dua panel local vs server, serta (4) verifikasi keberhasilan dilakukan dengan melihat folder/file yang muncul di remote dan memastikan transfer selesai.

Catatan untuk sesi belajar interaktif: tutor bisa memicu pemahaman konseptual dengan pertanyaan “kalau port 21 tidak terbuka, apa yang terjadi?”, “jika anonymous login tidak ada, apa alternatifnya?”, dan “kenapa upload harus dari panel kiri ke kanan?”. Tutor juga bisa mengaitkan ke keamanan dan etika: scanning dan akses server harus dilakukan pada lingkungan yang memang kamu punya izin (misalnya lab/ujicoba). Dengan cara itu, peserta tidak hanya hafal langkah, tapi juga paham alasan di balik setiap tahapan.
