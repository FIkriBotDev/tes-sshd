Python adalah bahasa pemrograman tingkat tinggi yang dirancang agar mudah dibaca dan dipelajari. Python dibuat oleh Guido van Rossum pada tahun 1991 dan kini populer untuk Ilmu Data (Data Science), Kecerdasan Buatan (AI), serta Pengembangan Web. Keunggulan belajar Python antara lain sintaks yang sederhana, komunitas besar dengan banyak library, serta dukungan multi-platform seperti Windows, Mac, dan Linux.

Dalam materi ini, kamu mempelajari dasar-dasar Python mulai dari pengenalan bahasa, variabel dan tipe data (integer, float, string, dan boolean), operator dasar (+, -, *, /, **), struktur kontrol (if, elif, else), perulangan (for dan while), struktur data (list, tuple, dictionary), hingga fungsi (function). Materi ini berfungsi sebagai fondasi sebelum melangkah ke library khusus seperti NumPy, Pandas, dan Django.

Materi membahas fondasi pemrograman Python untuk pemula yang mencakup pengenalan bahasa hingga konsep dasar pemrosesan logika dan data. Bagian awal menjelaskan bahwa Python merupakan bahasa pemrograman tingkat tinggi yang mudah dibaca dan dipelajari. Penekanan utama adalah keterbacaan sintaks dan kenyamanan bagi pemula. Materi juga menyebutkan asal-usul Python: diciptakan oleh Guido van Rossum pada tahun 1991. Selanjutnya dijelaskan alasan mengapa Python penting dan banyak dipakai: Python sangat populer untuk Ilmu Data (Data Science), Kecerdasan Buatan (AI), serta Pengembangan Web. Popularitas ini ditopang oleh ekosistem library dan komunitas yang besar. Dari sudut pandang praktis, Python memiliki sintaks yang sederhana dan mirip bahasa Inggris, sehingga lebih cepat dipahami. Python juga dapat dijalankan di berbagai sistem operasi (multi-platform), yaitu Windows, Mac, dan Linux. Bab berikutnya memperkenalkan konsep variabel dan tipe data. Variabel berfungsi sebagai wadah untuk menyimpan data, misalnya nama, umur, tinggi, dan status siswa. Dalam Python, tidak ada kebutuhan untuk mendeklarasikan tipe data secara eksplisit, karena tipe data ditentukan secara dinamis berdasarkan nilai yang dimasukkan. Materi merangkum tipe data dasar: integer untuk bilangan bulat (contoh 10 dan -5), float untuk bilangan desimal (contoh 3.14 dan 2.0), string untuk teks yang diapit kutip (contoh "Halo Dunia"), dan boolean untuk nilai logika True atau False. Materi memberikan contoh pembuatan variabel: nama = "Budi", umur = 20, tinggi = 175.5, dan is_student = True. Terdapat pula contoh penggunaan print dengan format string f-string untuk menampilkan data: print(f"Nama: {nama}, Umur: {umur}"). Poin penting yang perlu ditekankan kepada tutor: jelaskan bahwa f-string memudahkan penyisipan variabel ke dalam output.

Setelah itu materi masuk ke operator dasar. Tutor perlu membantu peserta memahami bahwa operator digunakan untuk melakukan operasi pada nilai atau variabel. Materi memuat tabel operator: + untuk penjumlahan (contoh 5 + 2 = 7), - untuk pengurangan (5 - 2 = 3), * untuk perkalian (5 * 2 = 10), / untuk pembagian (5 / 2 = 2.5), dan ** untuk perpangkatan (5 ** 2 = 25). Dengan pemahaman operator, peserta dapat mengolah angka dan menghasilkan nilai yang akan dipakai pada logika berikutnya.

Kemudian materi membahas struktur kontrol (percabangan). Tutor perlu menjelaskan peran if, elif, dan else sebagai mekanisme pengambilan keputusan. Materi contoh menetapkan nilai = 85 dan memetakan ke grade berdasarkan rentang: jika nilai >= 90 maka Grade: A, jika nilai >= 75 maka Grade: B, selain itu Grade: C. Ini mengajarkan bahwa urutan pengecekan penting dan elif digunakan untuk kondisi lanjutan yang tidak memenuhi kondisi sebelumnya.

Selanjutnya materi mengajarkan perulangan (loops) dengan dua jenis utama: for dan while. Tutor perlu menekankan kapan menggunakan masing-masing. Untuk for loop, materi memberi contoh for i in range(5): print(f"Iterasi ke-{i}") yang menunjukkan iterasi sebanyak 5 kali (indeks 0 sampai 4). Untuk while loop, materi memberi contoh count = 0; while count < 3: print("Halo!"); count += 1. Di sini, while berjalan selama kondisi masih benar, dan variabel count diubah agar loop berhenti. Penguatan konsep yang baik adalah menjelaskan bahwa while berpotensi infinite loop bila kondisi tidak diubah.

Bab berikutnya membahas struktur data: list, tuple, dan dictionary. Tutor perlu menjelaskan fungsi masing-masing dalam menyimpan koleksi. List adalah terurut dan bisa diubah (contoh buah = ["Apel", "Jeruk"]). Tuple adalah terurut namun tidak bisa diubah (contoh koordinat = (10, 20)). Dictionary berisi pasangan kunci dan nilai (key-value), contohnya user = {"nama": "Andi", "usia": 25}. Tutor sebaiknya menekankan bahwa dictionary cocok untuk data berbasis label (nama bidang sebagai kunci) sehingga akses data lebih jelas.

Terakhir materi membahas fungsi (function). Fungsi adalah blok kode yang hanya berjalan saat dipanggil. Materi memberikan contoh definisi: def sapa(nama): return f"Halo, {nama}! Selamat belajar Python." Lalu fungsi dipanggil dengan sapa("Andi") dan hasilnya dicetak. Tutor perlu menguatkan konsep bahwa fungsi membantu membuat kode modular, mengurangi pengulangan, dan memudahkan pengujian serta penggunaan ulang.

Materi penutup menegaskan bahwa pemrograman Python sangat luas dan materi yang diberikan adalah fondasi penting.
