Materi course ini:
Belajar Java dari nol lewat cerita sejarah, konsep teknologi (JVM dan Java API), sampai langkah praktis membuat dan menjalankan program pertama. Kamu juga akan memahami struktur class, method main, serta ide class driver yang memakai class lain.

Materi ini adalah pengantar pemrograman dengan Java, bagian awal yang memperkenalkan sejarah singkat Java, alasan Java populer, serta konsep dasar bagaimana program Java dieksekusi sampai ke struktur class dan contoh program pertama (HelloWorld). Kamu bisa mengajarkan materi ini dengan gaya “dari besar ke kecil”: mulai dari gambaran apa itu Java, lalu masuk ke komponen teknologinya (JVM dan Java API), kemudian bagaimana cara menyiapkan tools (JDK, editor teks, dan pengaturan PATH), lalu contoh program pertama serta makna class dan main.  Sejarah Java: materi menyebut Java dibuat oleh James Gosling saat ia masih bergabung di Sun Microsystems. Java dirilis tahun 1995. Ada slogan “Write once, run anywhere!” yang berarti program yang ditulis sekali dapat dijalankan di berbagai komputer/platform. Java adalah bahasa pemrograman tujuan umum (general purpose). Sintaks Java mengadopsi gaya dari C dan C++ namun dibuat lebih sederhana sehingga lebih mudah dipelajari. Menariknya, nama “Java” diambil dari jenis kopi yang diminum oleh James Gosling pada saat itu. Selain itu materi memberi konteks popularitas Java dengan data peringkat top programming languages pada tahun 2015 (masih top 10), 2017 turun ke peringkat 3, dan 2018 masih bertahan pada daftar top 10. Ini bisa digunakan untuk memotivasi siswa: Java bukan cuma “pernah populer”, tapi juga relevan cukup lama.  Teknologi Java: materi menekankan bahwa Java itu bukan sekadar bahasa, tapi “teknologi” yang terdiri dari bahasa pemrograman dan platform eksekusinya. Java punya karakteristik: sederhana, berorientasi objek, interpreted, terdistribusi, tangguh, portable, memiliki kinerja tinggi, aman, dan dinamis. Untuk memahami karakter interpreted dan portable, materi menjelaskan proses kompilasi dan interpretasi: compiler Java mengubah kode program menjadi intermediate bernama Java bytecode. Lalu ada interpreter/engine di runtime bernama JVM (Java Virtual Machine) yang menginterpretasi bytecode setiap kali bytecode dijalankan. Jadi, compile tidak langsung mengubah ke machine code spesifik perangkat, melainkan ke bytecode yang netral.  Java sebagai platform: materi mendefinisikan platform sebagai lingkungan perangkat keras dan perangkat lunak untuk menjalankan program. Java adalah platform perangkat lunak untuk menjalankan program Java. Platform Java terdiri dari dua komponen utama: (1) JVM dan (2) Java API. JVM pada dasarnya adalah aplikasi sederhana yang ditulis dalam bahasa C untuk mengeksekusi program yang ditulis dalam Java. Cara kerja JVM saat eksekusi adalah: JVM membaca bytecode, lalu mengubahnya menjadi bahasa mesin yang sesuai dengan komputer yang menjalankan. Intinya: bytecode selalu sama untuk tiap sistem operasi/jenis mesin, sedangkan JVM yang akan mengadaptasi ke bahasa mesin target.  Java API: materi menekankan bahwa Java API adalah library yang disediakan Java untuk memudahkan pemrogram Java mengembangkan aplikasi. Java API berisi kumpulan komponen perangkat lunak (class-library) yang membantu developer membuat fitur-fitur, misalnya penanganan input/output, struktur data, dan utilitas. Materi memberi contoh output melalui System.out.println pada bagian HelloWorld.  Edisi Java: materi menyebut tiga edisi Java dari Sun Microsystems. Pertama Java Standard Edition (J2SE) untuk aplikasi java secara umum. Kedua Java Micro Edition (J2ME) untuk perangkat dengan keterbatasan memori dan prosesor seperti mobile dan wireless. Ketiga Java Enterprise Edition (J2EE) untuk pengembangan aplikasi besar. Walau materi tidak terlalu dalam membahas perbedaan edisi, penting untuk siswa menangkap bahwa Java punya “varian” lingkungan sesuai target aplikasi.  Kakas Java: materi menjelaskan perlunya beberapa tools. Untuk menulis program Java, diperlukan Java Standard Edition (J2SE) dengan cara mengunduh paket SDK Java terbaru dari situs resmi. Selain itu dibutuhkan editor teks: Notepad, Ultraedit, Wordpad, Vi, Joe. Untuk pengembangan aplikasi visual (visual programming), diperlukan kakas pengembangan yang mengintegrasikan beberapa hal: JDK, editor teks, GUI editor (Graphical User Interface), manajemen aplikasi, dan debugger. Contoh IDE yang disebut adalah Netbeans dan Eclipse. Lalu ada langkah instalasi JDK, dan pengaturan environment variable PATH melalui Control Panel > System > Advanced > Environment Variables. Materi juga mengingatkan untuk mengecek versi JRE dan versi JDK yang terinstal (agar proses compile dan run sesuai).  Program pertama: bagian ini mengajarkan urutan praktis membuat program HelloWorld. Langkahnya: ketik program HelloWorld di editor teks, simpan sebagai HelloWorld.java (nama file harus sama persis dengan nama class). Kemudian kompilasi dari command prompt untuk menghasilkan arsip HelloWord.class (nama class yang konsisten penting; pada materi ada sedikit typo penulisan HelloWord vs HelloWorld, tapi konsepnya: output file .class muncul setelah compile). Setelah itu jalankan arsip .class dari command prompt hingga muncul output “Hello world!”.  Class (OOP): materi selanjutnya menguatkan konsep class. Java berorientasi objek; struktur Java terdiri dari kelas-kelas objek. Class adalah blueprint, sedangkan objek adalah instans dari class pada saat running. Template class: class NamaKelas { // body }. Di dalam class terdapat atribut dan method. Atribut dinyatakan dengan variabel atau objek kelas lain. Method adalah operasi (prosedur, fungsi, atau konstruktor) yang dimiliki oleh class. Contoh class HelloWorld hanya punya satu method yaitu main: public static void main(String[] args) { System.out.println("Hello world!"); }. Ini penting sebagai baseline: siswa harus paham bahwa program dieksekusi mulai dari main.  Program input/output sederhana: materi menyebut contoh InputTest.java dan proses compile lalu menjalankan programnya. Selanjutnya ada InputTestGUI.java untuk input menggunakan GUI. Materi juga menunjukkan pola yang lebih besar: ada Kelas Mahasiswa (Mahasiswa.java) dan Kelas DriverMhs (DriverMhs.java) yang menggunakan kelas Mahasiswa. Konsep ini bisa dijelaskan sebagai pemisahan tanggung jawab: Mahasiswa menyimpan data/behavior, sementara DriverMhs mengatur alur program (membuat objek, memanggil method, menampilkan hasil). Lalu ada contoh Kelas Matriks dan DriverMatriks, yang juga menggunakan Mahasiswa. Intinya: cara menyusun program multi-class adalah membuat beberapa class yang saling bekerja, dan class driver sebagai pengendali eksekusi.  Cara menjelaskan dengan friendly: ajak siswa membayangkan compile seperti mengubah resep menjadi bentuk yang bisa diproses oleh mesin (bytecode), JVM seperti juru masak yang menyesuaikan kompor tiap rumah (OS/CPU). Saat masuk ke class, gunakan analogi blueprint-baju atau cetakan-kue: class adalah blueprint, objek adalah produk jadi. Saat masuk driver class, gunakan analogi pengontrol lomba: kelas Mahasiswa/Matriks adalah peserta dan aturan, sedangkan Driver adalah panitia yang memanggil dan menjalankan proses.  Supaya pembelajaran terasa interaktif, tutor bisa mendorong siswa untuk selalu mengulang pola: ubah kode, compile, lalu jalankan untuk melihat output. Untuk bagian code, meskipun materi aslinya Java, playground di platform pembelajaran bisa berupa simulasi output (misalnya main dan System.out.println) agar siswa tetap berlatih logika dan fokus pada konsep alur eksekusi dan struktur program.
