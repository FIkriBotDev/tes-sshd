Materi utama:
Materi ini menjelaskan panduan praktikum konfigurasi perangkat jaringan Cisco pada sebuah lab yang terdiri dari router, switch, akses point (AP), serta server uji aplikasi. Topologi lab menekankan bahwa nilai “X” menyesuaikan nomor kelompok, router Cisco 1921 bertindak sebagai gateway ke internet, switch Cisco 2960-C digunakan untuk meneruskan beberapa VLAN, AP Wifi mendistribusikan LAN ke client, dan terdapat server web untuk kebutuhan pengujian aplikasi.

Materi kemudian membahas cara mengakses perangkat menggunakan kabel USB Console dan terminal emulator seperti PuTTY. Setelah akses CLI berhasil, dilakukan konfigurasi router meliputi hostname, pengaturan username/password/secret, pengaktifan remote telnet via line vty, pengaturan SNMP untuk kebutuhan monitoring NMS, konfigurasi interface WAN (ip nat outside), interface trunk, pembuatan sub-interface VLAN (ip nat inside), routing default, access-list untuk NAT, serta pembuatan NAT pool dan rule NAT. Terakhir, materi mengajarkan penyimpanan konfigurasi dan pengujian koneksi termasuk test ping serta pengecekan NAT.

Bagian berikutnya menguraikan konfigurasi switch meliputi hostname, hak akses, telnet, SNMP, setup trunk ke router, setup port akses untuk VLAN server/wifi, pembuatan interface VLAN manajemen agar switch dapat diremote, routing default ke gateway manajemen, serta perintah pengecekan status interface dan penyimpanan konfigurasi. Materi juga mencakup konfigurasi akses point lewat web browser (default IP 192.168.0.254, user/password admin), penyesuaian konfigurasi Wireless, penyelarasan IP AP dengan network gateway router, penentuan DHCP pada AP atau disable bila DHCP sudah ada di Cisco, dan pengaktifan SNMP agent untuk monitoring.

Sebagai opsional, materi menjelaskan instalasi server Network Monitoring System (NMS) menggunakan PRTG. Proses mencakup persiapan konektivitas PC ke jaringan, download PRTG dari situs resmi, instalasi dengan mode express, penginputan email, pengelolaan lisensi/trial, hingga penambahan group, device, pembuatan sensor (misalnya ping dan SNMP trafik), serta pembuatan dashboard menggunakan fitur Map untuk memvisualisasikan monitoring.

Materi panduan ini adalah modul praktikum konfigurasi <strong>router dan switch Cisco</strong> pada sebuah lab jaringan yang juga mencakup konfigurasi <strong>Access Point (AP)</strong> dan <strong>opsional</strong> instalasi <strong>NMS PRTG</strong> untuk monitoring. Fokusnya adalah langkah-langkah praktis agar peserta dapat membangun konektivitas VLAN, melakukan akses remote, menerapkan NAT agar LAN dapat terhubung ke internet, serta menyiapkan mekanisme monitoring.

Pada bagian awal, materi menjelaskan topologi lab dan makna parameter “X” (disesuaikan nomor kelompok). Peran perangkat pada topologi: Cisco 1921 dijadikan router/gateway ke internet, sedangkan Cisco 2960-C sebagai switch yang meneruskan beberapa VLAN. AP WiFi bertugas mendistribusikan LAN ke client nirkabel. Terdapat juga server web untuk kebutuhan pengujian aplikasi. Dengan adanya server web, konfigurasi NAT, routing default, dan VLAN diharapkan bekerja sehingga client (baik wired maupun wireless) dapat mengakses layanan yang berada di jaringan internet/target sesuai skenario lab.

Setelah topologi dipahami, materi mengajarkan cara mengakses perangkat. Akses menggunakan <strong>kabel USB Console</strong> ke laptop. Peserta harus memeriksa Device Manager untuk menentukan nomor <strong>COM port</strong> yang terdeteksi pada komputer. Setelah mengetahui COM misalnya COM3, peserta menggunakan terminal emulator seperti PuTTY untuk terhubung ke perangkat. Tujuan bagian ini adalah memastikan CLI Cisco muncul sehingga perintah konfigurasi dapat dilakukan.

Konfigurasi router meliputi beberapa blok besar. Pertama, identitas: masuk ke mode konfigurasi (configure terminal) lalu set hostname misalnya ROUTER-GROUP1. Kedua, keamanan akses: mengatur username dengan privilege tinggi (contoh privilege 15), password, serta enable secret untuk mengamankan mode administrator penuh. Materi menekankan konsep <strong>privilege level</strong> 0-15. Privilege level 15 adalah penuh/superuser. Ketiga, mengenkripsi password yang tersimpan di konfigurasi menggunakan service password-encryption. Keempat, mengaktifkan remote access melalui telnet: line vty 0 4 diberi login local dan transport input/output telnet. Materi menjelaskan kapasitas koneksi bersamaan: vty 0 4 berarti maksimal 5 sesi (0 sampai 4). Kelima, monitoring: SNMP server diset dengan community public RO agar NMS bisa membaca metrik tanpa perubahan.

Tahap berikutnya adalah konfigurasi interface dan NAT. Interface WAN (contoh GigabitEthernet0/0) diaktifkan (no shutdown), diberi description, di-set IP sesuai skema WAN, dan diberi ip nat outside. Interface trunk (GigabitEthernet0/1) disiapkan untuk membawa VLAN ke switch. Trunk biasanya tidak diberi ip address agar berfungsi sebagai link layer-2.

Agar beberapa jaringan LAN dapat dipisahkan, router membuat <strong>sub-interface VLAN</strong> pada interface trunk. Contoh yang diberikan: VLAN 10 untuk LAN server (Gi0/1.10 dengan encapsulation dot1Q 10, ip address, dan ip nat inside), VLAN 20 untuk LAN wifi (Gi0/1.20), dan VLAN 30 untuk LAN manajemen (Gi0/1.30). Pemberian ip nat inside menandai bahwa trafik dari subnet-subnet ini adalah kandidat yang akan diterjemahkan (di-NAT-kan) ke sisi internet.

Supaya router bisa mengirim trafik menuju jaringan yang bukan subnet lokal, dibuat <strong>routing default</strong> ip route 0.0.0.0 0.0.0.0 <WAN-GW-IP>. Lalu dibentuk access-list untuk menentukan subnet LAN mana yang boleh NAT. Contoh materi memasukkan rule permit untuk subnet LAN tertentu.

Implementasi NAT melibatkan pembuatan <strong>IP NAT pool</strong> pada IP WAN yang tersedia, lalu mengaitkan pool tersebut ke access-list menggunakan overload agar banyak host LAN bisa berbagi IP NAT pool. Selain dynamic NAT/overload, materi juga memberikan contoh <strong>static mapping</strong> ip nat outside source static untuk memetakan IP publik tertentu ke IP internal tertentu (misalnya untuk kebutuhan layanan khusus). Materi juga menyediakan opsi NAT berdasarkan port menggunakan perintah ip nat outside source static tcp ... <port> untuk kasus spesifik, dengan catatan bahwa jika NAT full sudah berjalan maka perintah port-spesifik mungkin tidak diperlukan.

Setelah konfigurasi, penting untuk menyimpan menggunakan write atau write memory. Pengujian dilakukan dengan ping gateway dan internet, test koneksi internet dari source LAN (memastikan NAT berjalan), pengecekan status NAT, dan pengecekan IP yang terkoneksi ke perangkat Cisco.

Konfigurasi switch bersifat melengkapi router. Switch mengatur hostname, username/password/secret, dan telnet via line vty. SNMP diaktifkan untuk monitoring. Switch kemudian mengonfigurasi port trunk ke router pada interface Gi0/1: menentukan mode trunk, mengaktifkan interface, dan mengizinkan VLAN yang dibutuhkan (contoh allow vlan 10,20,30). Selanjutnya switch menyiapkan port akses untuk perangkat LAN pada interface FastEthernet (contoh Fa0/1 ke VLAN 10 dan Fa0/2 ke VLAN 20). Untuk memungkinkan manajemen switch dari jaringan luar, dibuat interface Vlan30 dengan IP manajemen dan gateway default ke router (ip default-gateway). Setelah konfigurasi, switch disimpan dan dilakukan pengecekan status interface, deskripsi, serta trunk.

Bagian AP menjelaskan pengkabelan dengan POE dan cara akses web management AP. Peserta mengatur IP pada laptop agar satu network dengan default management AP (default IP 192.168.0.254). Login default admin/admin, lalu sesuaikan password bila diminta. Materi menyuruh mengonfigurasi terlebih dahulu menu Wireless, kemudian mengatur IP Address AP agar sesuai dengan network gateway router agar AP saling terhubung dengan perangkat jaringan. DHCP server dijelaskan: DHCP di AP diset jika tidak ada DHCP lain di Cisco, tetapi jika DHCP sudah ada di jaringan Cisco maka DHCP pada AP harus disable. SNMP agent pada AP juga perlu diaktifkan untuk memungkinkan monitoring. Setelah itu dilakukan uji koneksi dari wifi client.

Bagian opsional instalasi NMS PRTG memandu peserta menyiapkan sistem monitoring. PRTG diinstal pada PC/laptop yang terhubung ke jaringan (contoh terhubung ke mikrotik port ether2) dan IP mengikuti skema (contoh 10.10.X.2/29). Peserta mengunduh PRTG dari situs Paessler, instal menggunakan mode express, menerima kebijakan, menginput email, dan menyelesaikan instalasi sampai muncul halaman setup. Lisensi dapat dicek di menu PRTG Status; jika trial habis, PRTG masih bisa dipakai namun terbatas 100 sensor. PRTG siap memonitor perangkat/host. Penambahan monitoring dilakukan dengan membuat group, menambahkan device (misalnya router dengan IP manajemen), lalu menambahkan sensor seperti ping dan SNMP trafik. Untuk visualisasi, materi menyarankan penggunaan fitur Map untuk membuat dashboard berdasarkan posisi/peran perangkat.

Secara keseluruhan, materi mengikat semua tahap menjadi satu alur: akses perangkat via console → konfigurasi dasar dan keamanan → konfigurasi VLAN trunking → NAT dan routing untuk akses internet → konfigurasi AP untuk klien nirkabel → monitoring via SNMP (router/switch/AP) dan NMS PRTG untuk melihat metrik jaringan.
