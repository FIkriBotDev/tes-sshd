Materi course ini:
Python itu bahasa pemrograman yang mudah dibaca dan dipelajari—cocok banget untuk AI, Data Science, dan Web. Di course ini kamu akan belajar fondasi Python: variabel, tipe data, operator, percabangan, perulangan, struktur data, dan fungsi lewat latihan bergaya game.

Materi membahas fondasi pemrograman Python untuk pemula. Pertama, pengenalan Python menjelaskan bahwa Python adalah bahasa pemrograman tingkat tinggi yang dirancang supaya mudah dibaca dan dipelajari. Disebutkan penciptanya yaitu Guido van Rossum yang membuat Python pada tahun 1991. Lalu, materi menekankan popularitas Python saat ini, terutama untuk bidang Ilmu Data (Data Science), Kecerdasan Buatan (AI), dan pengembangan Web. Alasan kenapa belajar Python juga dijelaskan lewat poin-poin: sintaksnya sederhana dan mirip bahasa Inggris sehingga lebih ramah pemula; Python memiliki komunitas besar dan pustaka (library) yang lengkap sehingga banyak kebutuhan bisa diselesaikan; Python juga multi-platform, bisa dijalankan di Windows, Mac, dan Linux.

Bagian berikutnya adalah variabel dan tipe data. Materi menjelaskan bahwa variabel adalah wadah untuk menyimpan data. Berbeda dari beberapa bahasa lain, di Python pengguna tidak perlu mendeklarasikan tipe data secara eksplisit—Python akan menentukan tipe berdasarkan nilai yang dimasukkan. Materi kemudian merinci tipe data dasar: Integer (bilangan bulat) contohnya 10 dan -5; Float (bilangan desimal) contohnya 3.14 dan 2.0; String adalah teks yang diapit kutip contohnya "Halo Dunia"; dan Boolean berisi nilai logika True atau False. Materi juga memberi contoh pembuatan variabel: nama = "Budi", umur = 20, tinggi = 175.5, is_student = True. Untuk menampilkan hasil, materi menunjukkan penggunaan print dengan formatted string (f-string): print(f"Nama: {nama}, Umur: {umur}"). Intinya, f-string membantu menyisipkan nilai variabel langsung ke dalam teks tanpa proses rumit.

Selanjutnya, materi membahas operator dasar. Operator dipakai untuk melakukan operasi pada variabel dan nilai. Tabel di materi mencantumkan + untuk penjumlahan (contoh 5 + 2 = 7), - untuk pengurangan (5 - 2 = 3), * untuk perkalian (5 * 2 = 10), / untuk pembagian (5 / 2 = 2.5), dan ** untuk perpangkatan (5 ** 2 = 25). Tutor perlu menekankan bahwa operator tersebut merupakan dasar yang sering dipakai saat membuat logika perhitungan dan keputusan program. Contoh yang bisa ditunjukkan kepada siswa: gunakan / untuk mendapatkan hasil desimal ketika pembagian tidak habis.

Bagian struktur kontrol (percabangan) memperkenalkan penggunaan if, elif, dan else. Konsepnya: program melakukan keputusan berdasarkan nilai kondisi. Materi memberi contoh logika grade: nilai = 85 (meski contoh menuliskan nilai = 85 sebelum if). Lalu if nilai >= 90: print("Grade: A"), elif nilai >= 75: print("Grade: B"), else: print("Grade: C"). Tutor perlu menjelaskan alur: cek kondisi dari atas; selama kondisi pertama benar, cabang itu yang dieksekusi, jika salah baru lanjut ke elif, dan jika semua kondisi salah maka masuk ke else.

Kemudian materi membahas perulangan (loops) dengan dua tipe utama: for dan while. Untuk for loop, materi menunjukkan contoh: for i in range(5): print(f"Iterasi ke-{i}"). Artinya loop mengulang berdasarkan range yang memberi batas jumlah iterasi. Tutor perlu mengarahkan bahwa i akan berubah dari 0 sampai 4 (karena range(5) berisi 0..4). Untuk while loop, materi memberi contoh: count = 0; while count < 3: print("Halo!"); count += 1. Tutor harus menekankan pentingnya pembaruan variabel (count += 1) agar kondisi while akhirnya menjadi salah dan loop berhenti; tanpa update bisa terjadi infinite loop.

Bagian struktur data menjelaskan list, tuple, dan dictionary. Struktur data dipakai untuk menyimpan koleksi data dalam satu variabel. Materi menerangkan: list terurut dan bisa diubah contohnya buah = ["Apel", "Jeruk"]. Tuple terurut tetapi tidak bisa diubah contohnya koordinat = (10, 20). Dictionary adalah kumpulan key dan nilai contohnya user = {"nama": "Andi", "usia": 25}. Tutor perlu membantu siswa membedakan: list/tuple fokus pada urutan data, sementara dictionary fokus pada pencarian lewat key (misalnya user["nama"]). Walau contoh akses dictionary tidak ditulis detail, ide utamanya bahwa dictionary menyimpan pasangan kunci-nilai.

Bagian terakhir sebelum penutup adalah fungsi (function). Materi menjelaskan bahwa function adalah blok kode yang hanya berjalan saat dipanggil. Syntax yang ditunjukkan: def sapa(nama): return f"Halo, {nama}! Selamat belajar Python.". Lalu pesan = sapa("Andi") dan print(pesan). Tutor perlu menekankan bahwa function menerima input (parameter nama) dan mengembalikan output (return). Ini membuat kode lebih rapi dan bisa dipakai ulang untuk banyak kasus tanpa menulis ulang logika.

Penutup materi menyatakan bahwa pemrograman Python sangat luas. Fondasi yang dipelajari di materi ini adalah langkah awal. Langkah selanjutnya yang direkomendasikan adalah mempelajari library seperti NumPy untuk matematika, Pandas untuk data, dan Django untuk web. Tutor sebaiknya mengaitkan bahwa konsep dasar (variabel, kontrol, loop, struktur data, function) adalah bekal penting untuk mempelajari library-library tersebut nanti.
