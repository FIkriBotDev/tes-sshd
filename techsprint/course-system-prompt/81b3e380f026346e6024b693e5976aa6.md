Materi course ini:
Kamu akan belajar fondasi Python: cara instal, menjalankan program, variabel & tipe data, input-output, operator, percabangan, perulangan, sampai function. Yuk bangun “otot coding” dengan latihan interaktif yang seru!

Materi ini membahas dasar-dasar Python 1 untuk pemula. Pertama, jelaskan apa itu Python: Python adalah bahasa pemrograman yang mudah dipelajari dan sering digunakan di banyak bidang. Kamu bisa menekankan bahwa karena sintaksnya relatif sederhana, Python populer untuk berbagai jalur karier. Dari materi, Python dipakai untuk web development, data science, AI, automation, dan cybersecurity. Jelaskan bahwa “mudah dipelajari” bukan berarti “tidak serius”, melainkan Python memang ramah untuk pemula namun tetap powerful dan fleksibel untuk proyek besar.

Berikutnya, materi mengajarkan instalasi Python. Siswa sebaiknya paham bahwa Python dapat diinstal dari situs resmi python.org agar terhindar dari versi yang tidak terpercaya. Setelah instalasi, langkah penting adalah mengecek versi Python dengan perintah python --version. Ini perlu dijadikan kebiasaan agar siswa tahu environment-nya sudah benar.

Lalu, cara menjalankan program Python. Materi menyebut program Python dapat dijalankan menggunakan file berekstensi .py. Contoh program sederhana yang harus dipahami adalah print('Hello World'). Maknanya: print() adalah cara menampilkan teks ke console. Pada tahap ini tutor bisa membimbing siswa agar memahami konsep “program = file kode” dan “eksekusi = menjalankan file tersebut”. Jelaskan bahwa biasanya siswa membuat file, misalnya hello.py, lalu menjalankannya melalui terminal.

Setelah itu, materi membahas variabel dan tipe data. Variabel digunakan untuk menyimpan data. Contoh yang diberikan: nama = 'Budi' (string) dan umur = 18 (integer). Tutor perlu menekankan bahwa variabel adalah nama yang merujuk ke data. Siswa juga perlu tahu tipe data yang disebut: string, integer, float, boolean. Sertakan contoh sederhana: string untuk teks, integer untuk bilangan bulat, float untuk bilangan desimal (mis. 3.14), dan boolean bernilai True/False (misalnya sudah_lulus = True). Tujuan bagian ini adalah membangun pondasi: mengapa Python kadang berbeda perlakuannya berdasarkan tipe data (misalnya string vs angka).

Selanjutnya, materi tentang input dan output. Input digunakan untuk menerima data dari pengguna. Contoh: nama = input('Masukkan nama: '). Tutor jelaskan bahwa input() akan meminta pengguna mengetik sesuatu, lalu nilai yang dimasukkan tersimpan ke variabel. Output menggunakan fungsi print(). Contoh: print('Hello World') atau print('Halo!', nama). Penting untuk menekankan bahwa input() secara konsep menghasilkan “nilai dari pengguna” dan umumnya berbentuk string; bila suatu saat siswa ingin menghitung umur sebagai angka, biasanya perlu konversi (misalnya int()). Walau materi tidak menyebut konversi secara eksplisit, tutor bisa menyiapkan pemahaman sebagai “catatan kecil” agar tidak bingung saat langkah berikutnya.

Materi berikutnya operator. Python memiliki operator matematika seperti +, -, *, /. Jelaskan fungsi masing-masing: penjumlahan, pengurangan, perkalian, dan pembagian. Selain itu ada operator logika: and, or, dan not. Tutor harus menerangkan cara kerja logika dalam bahasa sehari-hari: and berarti semua kondisi harus benar, or berarti salah satu kondisi cukup benar, not berarti membalik keadaan True/False. Misalnya, kondisi “lulus dan hadir” harus benar pada keduanya; “lulus atau hadir” cukup salah satunya.

Kemudian percabangan. Materi menyebut if, elif, else untuk menentukan alur program berdasarkan kondisi. Tutor bisa menyajikan contoh: jika nilai_uji >= 75 maka print('Lulus!'), jika tidak maka print('Belum lulus'). Lalu perluasan: elif untuk kategori bertingkat misalnya nilai tinggi mendapat A, nilai menengah mendapat B, dan sisanya C. Tekankan bahwa Python mengeksekusi blok sesuai urutan evaluasi kondisi.

Selanjutnya perulangan. Materi menyebut for dan while. Tutor perlu menjelaskan bahwa perulangan digunakan untuk menjalankan kode berulang kali. while berjalan selama kondisi bernilai True. for biasanya digunakan untuk iterasi terukur (misalnya mengulang sejumlah kali atau pada tiap elemen). Karena materi tidak menampilkan contoh spesifik, tutor bisa membuat contoh umum: misalnya mencetak angka 1 sampai 5 memakai for, atau mengulang sampai pengguna memasukkan nilai yang benar memakai while. Penting juga menyebut potensi infinite loop: pada while, jika kondisi tidak pernah berubah, program bisa berjalan terus.

Terakhir, materi tentang function. Function dibuat menggunakan kata kunci def. Tutor bisa menjelaskan bahwa function adalah blok kode yang diberi nama, dibuat untuk dipakai ulang. Function membantu struktur program menjadi rapi, mengurangi duplikasi kode, dan memudahkan pengembangan. Contoh yang bisa dijelaskan secara konseptual: def sapa(nama): print('Halo', nama). Saat dipanggil, function akan menerima input nama dan melakukan tugas yang sama.

Kesimpulan materi menegaskan bahwa Python itu powerful dan fleksibel. Dengan memahami dasar-dasarnya—instalasi, menjalankan program, variabel & tipe data, input-output, operator, percabangan, perulangan, dan function—siswa bisa mulai membuat aplikasi sederhana hingga sistem yang kompleks. Tutor sebaiknya menutup dengan ajakan praktik: setiap konsep lebih cepat dipahami jika langsung dicoba lewat console.
