Materi course ini:
Kamu akan merancang jaringan berbasis kabel dan nirkabel dengan VLAN (Siswa/Guru) lewat MikroTik Router A, lalu mengatur Hotspot, user profile, serta pembagian kecepatan. Setelah itu, kamu buat routing statis (NAT masquerade) agar jaringan bisa akses internet dan lanjut konfigurasi Switch Manageable (Router B) dengan VLAN secure.

Materi ini adalah pembahasan tugas UKK TKJ Paket 2 TA 2023/2024 berjudul Rancang Bangun Jaringan Berbasis Kabel dan Nirkabel dengan VLAN dan Routing. Tujuan praktikum: membangun jaringan dengan pemisahan segmen menggunakan VLAN pada Routerboard MikroTik (Router A sebagai router utama dan Router B sebagai switch manageable/VLAN capable), menyediakan akses internet, mengatur DHCP untuk client kabel maupun wireless, menyiapkan layanan Hotspot pada WLAN, serta membuat user profile untuk membedakan hak akses dan rate limit (kecepatan) masing-masing peran (kepala sekolah, guru, siswa). Materi juga menuntun pengubahan tampilan halaman login Hotspot agar ada tulisan selamat datang sesuai nama sekolah. A. Alat dan bahan: 2 unit PC/Laptop, 1 unit RB 900/951 Router (Router A), 1 unit RB 900/951 Switch Manageable/VLAN (Router B), 1 unit smartphone untuk pengujian WLAN, koneksi internet minimal 1 Mbps, dan 3 unit kabel UTP. Komponen ini relevan karena praktikum menguji fungsi ethernet (kabel) dan wireless (nirkabel), plus kebutuhan trunk VLAN agar tag VLAN dapat lewat dari switch ke router.
B. Langkah kerja Router A secara umum: Router A diakses menggunakan WinBox. Sebelum konfigurasi, dilakukan reset konfigurasi agar mulai dari keadaan bersih. Lalu router diberi identitas menggunakan System > Identity dengan format ROUTER A-(Nama Anda). Tujuannya memudahkan dokumentasi dan identifikasi perangkat saat ada lebih dari satu router. Setelah itu, diberi comment pada setiap ether yang digunakan agar tidak tertukar saat konfigurasi: ether1 diberi comment “Ineternet” (gateway internet) dan ether wireless/hotspot diberi comment “Hotspot”. 
C. Konfigurasi VLAN di Router A: VLAN 10 (vlan1-Siswa) dan VLAN 20 (vlan2-Guru) dikonfigurasi pada Ether2. Di WinBox, masuk menu Interface, klik tanda +, pilih VLAN general, atur nama dan VLAN ID, lalu pilih interface Ether2 sebagai tempat tag VLAN diterima. Konsep penting untuk tutor adalah bahwa interface trunk harus mampu membawa paket bertag VLAN. Ether2 di sini berperan sebagai sisi yang menerima VLAN dari perangkat upstream atau desain topologi yang diberikan.
D. Konfigurasi Ether1 sebagai gateway internet: Ether1 menggunakan DHCP Client. Langkahnya IP > DHCP Client > enable dan pilih interface ether1, tunggu sampai status bound. Setelah itu uji koneksi internet dengan Terminal: ping 8.8.8.8. Jika terkoneksi, lanjut langkah berikutnya. Inti pemahamannya: Router A harus punya akses internet terlebih dahulu sebelum melakukan NAT dan routing statis agar internal jaringan bisa internet.
E. Konfigurasi IP Address: Router A memiliki beberapa interface logis: vlan1-Siswa (IP VLAN 1), vlan2-Guru (IP VLAN 2), dan Wlan1 (IP WLAN). IP VLAN 1 ditetapkan 192.168.40.1/24 pada interface vlan1-Siswa. IP VLAN 2 ditetapkan 192.168.60.1/24 pada interface vlan2-Guru. IP WLAN ditetapkan 192.168.20.1/24 pada interface Wlan1. Ini membangun tiga segmen berbeda: jaringan kabel siswa, jaringan kabel guru, serta jaringan nirkabel (wireless) yang akan menggunakan Hotspot.
F. Konfigurasi DHCP Server: DHCP pool ditetapkan untuk masing-masing segmen agar client otomatis mendapatkan IP tanpa setting manual. Untuk vlan1-Siswa: range 192.168.40.10 sampai 192.168.40.50. Untuk vlan2-Guru: range 192.168.60.10 sampai 192.168.60.50. Untuk wlan1: range 192.168.20.10 sampai 192.168.20.50. Setup dilakukan lewat IP > DHCP Server > DHCP Setup, pilih interface yang sesuai lalu next sampai muncul address to give out dan sampai status successful. Tutor perlu menekankan bahwa gateway sudah ada pada interface VLAN/WLAN; DHCP hanya membagikan IP dalam pool dan mengarahkan gateway sesuai konfigurasi.
G. Konfigurasi Wireless dan Hotspot: 1) Wireless security profile: Wireless > Security Profile > + general. Nama “TKJ”, aktifkan WPA2PSK, set WPA Per-Shared Key “12345678”. 2) Wireless interface: double klik interface wlan1, set mode AP Bridge, band B/G/N, channel width 20/40 MHz Ce, SSID “UKK_Nama” (ganti dengan nama). Pilih security profile TKJ, lalu Apply/OK. 3) Hotspot: IP > Hotspot > Server > Hotspot Setup pilih Wlan1, next sampai DNS name “portalsmk.sch.id”, next dan set password “12345”, lalu OK. Setelah hotspot dibuat, buka Server profile, double klik hotpot1, pilih login, hilangkan centang pada bagian cookie, lalu OK. Lalu dibuatlah 5 user sesuai ketentuan profil. Pada materi dijelaskan tiga user: kepsek, guru, siswa, namun tertulis “Buatlah 5 user”; bagian yang benar dari tabel menunjukkan 3 user utama beserta password dan profile. Tutor harus mengarahkan siswa mengikuti daftar user yang disebut: kepsek (123), guru (456), siswa (789). Jika sekolah meminta 5 user, siswa bisa menambah user lain dengan pattern yang sama, tetapi harus tetap menggunakan profile dan password yang tersedia dalam soal.
H. Pembuatan user profile dan user: 1) Profile kepala sekolah: Hotspot > User Profil > general nama “kepsek”, Address pool: dhcp_pool2 (sesuai pool dhcp wireless yang dipakai pada interface wireless), Rate limit (rx/tx): 512k/512k, queue: Parent Queue none. 2) Profile guru: nama “guru”, Address pool dhcp_pool2, rate limit 256k/256k. 3) Profile siswa: nama “siswa”, Address pool dhcp_pool2, rate limit 128k/128k. Setelah itu buat user: user kepala sekolah server hotdpot1 (penulisan di materi hotdpot1/hotpot1 ada variasi typo; konsepnya user dibuat pada server hotspot yang telah dibuat, misalnya hotspot1), user “kepsek” password 123 profile kepsek. User guru: user “guru” password 456 profile guru. User siswa: user “siswa” password 789 profile siswa. Intinya cocokkan nama user, password, dan profile.
I. Ubah tampilan halaman login hotspot: Files > cari file hotspot/login.html, drag ke desktop, open with Notepad, cari teks “Please log on” dan ganti dengan “Selamat Datang di Hotspot SMKN 1 PANGKEP” (XXX = nama sekolah). Simpan, lalu drag file kembali ke menu Files di WinBox agar diterapkan.
J. Konfigurasi routing statis dan NAT untuk internet: Router A menjalankan NAT masquerade pada IP > Firewall > NAT rule: Chain = srcnat, out interface = ether1 (internet), action = masquerade. Setelah NAT dibuat, routing statis diatur lewat IP > Route. Pada baris gateway internet, Hapus row yang tidak diperlukan, lalu buat rule: Gateway 192.168.2.1 sesuai instruksi. Konsepnya: routing statis memberi jalur menuju internet melalui gateway upstream; NAT membuat traffic dari jaringan internal berhasil diterjemahkan.
K. Konfigurasi Router B (MIKROTIK B) sebagai Switch Manageable dengan VLAN secure dan always-strip: Router B diakses via WinBox, reset konfigurasi, lalu set identity “SWITCH-(Nama Anda)” sesuai materi. Konfigurasi VLAN mengikuti logika topologi: Port 1 terhubung ke WiFi Routerboard dan difungsikan sebagai port trunk (membawa tag VLAN), Port 2 dan 3 terhubung ke VLAN 1 (VLAN ID 10), Port 4 terhubung ke VLAN 2 (VLAN ID 20). Buat bridge: Bridge > + > general bridge 1_ (nama). Tambahkan interface: ether1 ether2 ether3 ether4 ke bridge pada menu Port. Lalu buat VLAN: pada Switch > VLAN tambahkan VLAN=10, isi ports dengan ether1 kemudian arrow bawah pilih ether2 dan ether3. VLAN=20: isi ports ether1 dan ether4. Setelah VLAN entries dibuat, atur mode per port: pada Port double klik ether1 set VLAN mode = secure, VLAN header add if missing, lalu Apply. Pada port access ether2 dan ether3 set VLAN mode secure, VLAN header always strip, Default VLAN ID 10, Apply. Port ether4 set VLAN mode secure, VLAN header always strip, Default VLAN ID 20, Apply. Tutor perlu menekankan perbedaan VLAN header add if missing vs always strip: add if missing pada trunk membantu menambahkan tag saat dibutuhkan; always strip pada access membuang tag sehingga client tidak perlu tahu VLAN.
L. Pengujian: Pasang perangkat sesuai desain topologi. Client PC kabel terhubung ke port 2 dengan IP Address DHCP pada Windows. Client laptop kabel terhubung port 4 dengan IP Address DHCP pada Windows. Client jaringan wireless menggunakan Android/Ios dengan IP Address DHCP. Jika VLAN dan DHCP benar, PC port 2 harus dapat IP segmen VLAN 10 (192.168.40.x), laptop port 4 dapat IP segmen VLAN 20 (192.168.60.x), dan smartphone dapat IP segmen WLAN (192.168.20.x) serta memunculkan halaman login Hotspot. Lalu pastikan juga akses internet berhasil sesuai NAT dan routing.
