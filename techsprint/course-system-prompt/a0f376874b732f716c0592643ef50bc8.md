Materi course ini:
Belajar SQL dari nol dengan cara yang interaktif: mulai dari SELECT, filter dengan WHERE, urutkan data, sampai fungsi-fungsi, join, dan subquery. Sekaligus kamu juga akan kenal fondasi perintah SQL seperti DML, DDL, dan DCL.

Materi ini berisi dua bagian besar: (1) pengantar dan ringkasan hukum terkait hak cipta (UU No 28 Tahun 2014, khususnya Pasal 4, Pasal 26, dan Pasal 113), serta (2) “Pengenalan Dasar SQL” yang membahas konsep dan perintah SQL dari level pemula. Untuk AI tutor, kita fokus membuat siswa memahami SQL secara bertahap sekaligus menyadari pentingnya etika penggunaan konten (hak cipta) saat belajar dan menggunakan materi. Bagian hukum: Pasal 4 menjelaskan bahwa Hak Cipta adalah hak eksklusif yang terdiri atas hak moral dan hak ekonomi. Hak moral berkaitan dengan keterkaitan nama/keutuhan karya, sedangkan hak ekonomi berkaitan dengan manfaat finansial dari karya. Pasal 26 menjelaskan pembatasan pelindungan hak cipta: beberapa penggunaan tertentu tidak perlu izin, misalnya penggunaan kutipan singkat untuk pelaporan peristiwa aktual yang ditujukan hanya untuk informasi aktual; penggandaan untuk penelitian ilmu pengetahuan; penggandaan untuk pengajaran dengan pengecualian untuk pertunjukan dan fonogram yang sudah dilakukan pengumuman sebagai bahan ajar; serta penggunaan untuk kepentingan pendidikan dan pengembangan ilmu pengetahuan yang memungkinkan suatu karya atau produk hak terkait digunakan tanpa izin pelaku pertunjukan, produser fonogram, atau lembaga penyiaran. Pasal 113 memberi gambaran sanksi pelanggaran, terutama untuk penggunaan secara komersial tanpa hak/izin. Disebutkan ancaman pidana penjara paling lama 1 tahun dan/atau denda paling banyak Rp100.000.000 untuk pelanggaran hak ekonomi tertentu, serta pidana penjara paling lama 3 tahun dan/atau denda paling banyak Rp500.000.000,00 untuk pelanggaran hak ekonomi pencipta untuk penggunaan komersial pada kategori pasal yang disebut. Tutor sebaiknya menjelaskan ini secara sederhana: materi dan contoh SQL di buku/slide adalah ciptaan yang dilindungi, tetapi ada batasan/pembatasan tertentu yang memperbolehkan kutipan singkat atau penggunaan untuk edukasi dan penelitian, namun tetap harus mengikuti aturan yang ada. Setelah konteks hak cipta, materi SQL: Tujuan buku adalah memberi fondasi SQL secara runtut dan sistematis, dilengkapi gambar (di dokumen daftar isi terlihat ada banyak topik). Urutan belajar yang tampak: Bagian 1: Pem batasan dan pengurutan data dengan SQL. Di dalamnya ada pengertian SQL dan mengenal perintah SQL; juga “Mempersiapkan Schema/User untuk Query Data”. Tutor harus menekankan bahwa sebelum menjalankan query, siswa perlu tahu skema (schema) dan tabel yang akan diakses, serta memastikan user punya izin. Bagian 2: Berinteraksi dengan SQL. Fokus pertama adalah menampilkan data dengan perintah SELECT. Materi mencakup: (1) kapabilitas perintah SQL SELECT, (2) perintah SELECT dasar termasuk seleksi semua kolom (SELECT *) dan seleksi sebagian kolom, (3) menulis perintah SQL (aturan sintaks umum, mis. SELECT ... FROM ...), (4) ekspresi aritmatik, (5) mendefinisikan nilai NULL, (6) kolom alias (AS), (7) operator concat, (8) karakter literal string, (9) operator quote (q) (biasanya terkait penulisan literal string tertentu), (10) duplikasi baris (menggambarkan konsep DISTINCT atau konsep duplikat output), dan (11) menampilkan struktur tabel. Setelah SELECT, masuk manipulasi data: INSERT, UPDATE, DELETE. Tutor bisa menjelaskan peran masing-masing: INSERT menambah baris, UPDATE mengubah baris yang memenuhi kondisi (biasanya kombinasi dengan WHERE), DELETE menghapus baris. Bagian 3 menguatkan pembatasan dan pengurutan data dengan klausa WHERE dan pengurutan. Tutor perlu mengajarkan: penggunaan klausa WHERE, operator pembanding BETWEEN, IN, LIKE, dan NULL. Lalu operator logikal AND, OR, NOT beserta prioritas urutan (misalnya ekspresi di dalam kurung dievaluasi lebih dulu, secara konsep logika). Setelah filtering, siswa belajar pengurutan data: DESC untuk descending, pengurutan dengan kolom alias, pengurutan berdasarkan nomor kolom (konsep yang mungkin berbeda antar DBMS), serta pengurutan beberapa kolom. Bagian 4 fokus fungsi-fungsi dalam SQL. Ini luas: (A) Single-row functions: fungsi karakter (LOWER, UPPER, INITCAP untuk konversi; CONCAT, SUBSTR, LENGTH, INSTR, LPAD/RPAD, TRIM, REPLACE untuk manipulasi string), fungsi number/angka (ROUND, TRUNC, MOD), fungsi tanggal (MONTHS_BETWEEN, ADD_MONTHS, NEXT_DAY, LAST_DAY, serta ROUND dan TRUNC yang relevan untuk tanggal), fungsi konversi (TO_CHAR, TO_NUMBER, TO_DATE), fungsi nested (menggambarkan nesting fungsi satu sama lain), fungsi umum lain (NVL, NVL2, NULL IF, COALESCE, kondisi ekspresi), kondisi ekspresi termasuk CASE (simple case dan searched case). Selain itu fungsi grup: AVG dan SUM (untuk tipe angka), MIN dan MAX (untuk angka, karakter, dan tanggal), COUNT, nilai null dalam fungsi grup, klausa grup (konsep grouping), dan fungsi grup nested (bersarang). Tutor harus membuat siswa memahami kapan fungsi bekerja per baris vs saat agregasi bekerja untuk kumpulan baris. (B) Multiple-row functions: natural join (dengan USING atau ON), self join, nonequi join, outer join (left, right, full), dan Cartesian products. Bagian 5 mengenai penggunaan sub query: perintah sub-query dan macam sub-query: single-row operation dan multiple-row operation. Tutor sebaiknya memberi pemahaman intuitif: subquery sebagai “query untuk menghasilkan nilai/daftar” yang kemudian dipakai oleh query utama untuk seleksi atau pembatasan. Untuk membuat tutor friendly, gunakan pendekatan bertahap: contoh kasus seperti data mahasiswa/produk/pelanggan; mulai dari menampilkan semua data, lalu pilih kolom tertentu, lalu filter dengan WHERE, lalu urutkan, lalu tambahkan fungsi untuk transformasi output, lalu join untuk menyatukan informasi dari beberapa tabel, lalu subquery untuk kasus filter berbasis hasil query lain. Selain konsep, tutor juga harus menekankan etika: jangan menyalin konten secara mentah; gunakan kutipan singkat untuk laporan/informasi aktual, untuk penelitian/pengajaran bisa ada pengecualian sesuai Pasal 26, dan pahami bahwa pelanggaran hak ekonomi untuk penggunaan komersial dapat dikenai sanksi sesuai Pasal 113.
