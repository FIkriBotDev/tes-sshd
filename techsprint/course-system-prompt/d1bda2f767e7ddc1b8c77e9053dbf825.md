Materi course ini:
Kamu akan belajar asal-usul JavaScript, kenapa JavaScript penting di web, lalu cara menulis skrip pertama di HTML. Setelah itu kamu praktikkan variabel, tipe data, operator, dan cara memasukkan data lewat form (input, radio, checkbox, textarea, select).

Modul 1 membahas pengantar JavaScript: sejarah singkat, peran bahasa sebagai skrip web, kebutuhan dasar untuk belajar, cara penulisan di HTML, program pertama, serta komentar. Materi menjelaskan bahwa JavaScript diperkenalkan oleh Netscape pada tahun 1995. Pada awalnya bahasa ini bernama LiveScript dan berfungsi sebagai bahasa sederhana untuk browser Netscape Navigator 2. Saat itu JavaScript mendapatkan banyak kritik karena isu keamanan, pengembangannya yang terasa terburu-buru, serta minimnya pesan kesalahan ketika terjadi kesalahan sintaks saat menulis program. Lalu karena kerjasama antara Netscape dan Sun (pengembang bahasa pemrograman Java), Netscape memberikan nama JavaScript pada tanggal 4 Desember 1995. Pada waktu yang sama, Microsoft mengadaptasi teknologi ini di Internet Explorer 3 dengan istilah Jscript. Dari sisi konsep, JavaScript digambarkan sebagai bahasa berbentuk kumpulan skrip yang berjalan pada dokumen HTML. Sepanjang sejarah internet, JavaScript disebut sebagai bahasa skrip pertama untuk web yang memungkinkan kemampuan tambahan terhadap HTML. Artinya, JavaScript memberi interaksi/aksi di sisi user, khususnya di sisi browser, bukan di sisi server web. JavaScript bergantung pada browser yang memanggil halaman web yang mengandung skrip, dan skrip biasanya terselip di dalam dokumen HTML. Materi juga menekankan bahwa JavaScript tidak memerlukan kompilator atau penterjemah khusus untuk menjalankannya; kompilator JavaScript sudah termasuk dalam browser. Ini dibandingkan dengan Java yang memerlukan kompilator khusus di sisi user/klien.

Selanjutnya, modul membahas keperluan belajar JavaScript: dua piranti utama yaitu teks editor dan web browser. Teks editor digunakan untuk menuliskan kode JavaScript, contohnya Notepad dan Ultra Edit. Web browser digunakan untuk menampilkan halaman yang mengandung kode JavaScript, dan browser harus mendukung JavaScript; contoh yang disebut adalah Internet Explorer dan Netscape Navigator. Bagian penulisan JavaScript menjelaskan bahwa kode JavaScript ditulis pada file HTML, dengan dua cara. Pertama, menulis JavaScript pada file yang sama dengan HTML: gunakan tag <SCRIPT LANGUAGE="JavaScript"> program </SCRIPT> yang biasanya diletakkan di antara tag <BODY>…</BODY>. Contoh strukturnya ditunjukkan: <HTML><HEAD>…</HEAD><BODY><SCRIPT LANGUAGE="JavaScript"> kode javascript </SCRIPT> kode HTML lain </BODY></HTML>. Kedua, menulis JavaScript pada file terpisah: dibuat file berekstensi .js lalu dipanggil dari HTML menggunakan <SCRIPT SRC="namafile.js">…</SCRIPT>. Karena logika JavaScript sudah berada di file terpisah, di dalam tag SCRIPT pada HTML tidak perlu menuliskan kode JavaScript lagi.

Materi kemudian masuk ke program pertama JavaScript yang menampilkan teks "Belajar Pemrograman Javascript". Contoh kode memakai document.write di dalam tag SCRIPT. Ada penekanan penggunaan document.write dan document.writeln: document.write menulis teks tanpa ganti baris, sedangkan document.writeln menulis teks dengan ganti baris. Materi juga memberi contoh lain yang menampilkan beberapa baris dan format menggunakan tag HTML seperti <PRE>, <B>, <FONT SIZE=5>, <I> melalui document.write/writeln. Penjelasan selanjutnya adalah contoh ketika JavaScript diletakkan di file lain (misalnya isi.js) lalu dipanggil dari file HTML. File isi.js berisi document.writeln untuk membangun tampilan seperti garis HR dan judul-judul universitas, sedangkan HTML memanggilnya lewat <SCRIPT language="JavaScript" SRC="isi.js"></SCRIPT>.

Bagian komentar menjelaskan fasilitas untuk menuliskan komentar seperti bahasa pemrograman lain. Komentar berguna agar ketika kamu atau orang lain membaca program di kemudian hari, mereka mudah memahami maksud kode. Dua cara komentar yang diajarkan adalah // untuk komentar satu baris, dan /* ... */ untuk komentar blok. Ini penting karena membantu dokumentasi internal saat latihan, apalagi ketika program semakin panjang.

Modul 2 berfokus pada variabel dan tipe data serta operator. Modul 2.1 membahas variabel: variabel digunakan untuk menyimpan nilai atau informasi. Materi menyebutkan ada pendeklarasian yang bersifat opsional: kamu boleh mendeklarasikan atau tidak, tidak menjadi masalah; jika memberi nilai pada variabel, JavaScript menganggap variabel sudah dideklarasikan. Aturan penamaan variabel yang disebut: harus diawali karakter (huruf atau underscore), tidak boleh menggunakan spasi, huruf kapital dan kecil memiliki arti berbeda, dan tidak boleh menggunakan kata-kata yang merupakan perintah dalam JavaScript. Sintaks deklarasi yang dicontohkan: var nama_variabel = nilai atau Nama_variabel = nilai, termasuk contoh var nama; var nama = "Zaskia Mecca"; var X=1998; var Y; Nama="Bunga Lestari"; X=1990; Y=08170223513. Modul 2.2 membahas tipe data implisit: berbeda dari bahasa lain yang mungkin mendeklarasikan tipe secara eksplisit, JavaScript tidak memiliki tipe data secara eksplisit. Namun JavaScript mempunyai tipe data implisit, dengan empat macam tipe yang dibahas: Numerik (misalnya 0222532531, 1000, 45, 3.146789), String (misalnya "Hallo", "April", alamat dalam teks), Boolean (true/false), dan Null (variabel yang tidak diinisialisasi).

Modul 2.3 membahas tipe numerik: JavaScript mengenal dua macam tipe numerik yaitu bilangan bulat (integer) dan bilangan pecahan (real/float). Untuk integer bisa direpresentasikan dalam basis desimal, oktal, atau heksadesimal. Materi memberi contoh var A=100; var B=0x2F. Untuk bilangan pecahan/real bisa menggunakan tanda titik atau notasi ilmiah (notasi E). Contoh: var a=3.14533567; var b=1.23456E+3. Modul 2.4 membahas tipe string: string dituliskan di antara tanda petik tunggal '...' atau petik ganda "...". Modul 2.5 membahas boolean: hanya true atau false, biasanya dipakai mengecek kondisi. Contoh var X = (Y > 90); yang berarti jika Y lebih besar dari 90 maka X bernilai True. Modul 2.6 membahas null: tipe null untuk variabel yang tidak diberi nilai awal.

Modul 2.7 membahas operator yang terbagi menjadi enam: operator aritmatika, operator pemberian nilai (assign), operator manipulasi bit, operator pembanding, operator logika, dan operator string (gabungan). Materi menjelaskan operator aritmatika: numerik tunggal dan biner. Contoh biner untuk penjumlahan +, pengurangan -, perkalian *, pembagian /, modulus %. Operator tunggal meliputi negasi -, serta ++ (penambahan dengan satu) dan -- (pengurangan dengan satu). Modul 2.7b membahas operator pemberian nilai: = sama dengan, += setara dengan X=X+Y, -= setara dengan X=X-Y, *=, /=, %= serta juga termasuk &= (bit AND), |= (bit OR). Materi 2.7c operator manipulasi bit: & AND, | OR, ^ XOR, ~ NOT, << geser kiri, >> geser kanan, >>> geser kanan dengan pengisian nol. Materi memberi contoh A=12 (1100b), B=10 (1010b), C=A&B menghasilkan 1000b, lalu contoh A<<2 menjadi 48 dan A>>1 menjadi 6. Modul 2.7d operator pembanding: == sama dengan, != tidak sama dengan, >, <, >=, <=; operator ini bisa membandingkan numerik, string, maupun ekspresi. Modul 2.7e operator logika: && AND, || OR, ! NOT, dengan contoh A=true, B=false menghasilkan C=false untuk A&&B, D untuk A||B, dan E=!A. Terakhir materi 2.7f operator string: penggabungan string menggunakan tanda +.

Modul 2.8 membahas memasukkan data dari keyboard menggunakan perintah input. Contoh program memakai fungsi jumlah() yang membaca bilangan dari form (document.fform.bilangan1.value dan bilangan2.value), mengubahnya jadi angka dengan parseFloat, lalu mengecek isNaN untuk memastikan jika input bukan angka, nilainya diset 0.0. Kemudian hasil penjumlahan ditampilkan lewat alert dengan string 'Hasil Penjumlahan = ' + hasil. Materi memberi latihan: memodifikasi program sebelumnya agar bisa melakukan pengurangan, perkalian, dan pembagian. Ini berarti siswa perlu membuat logika operasi lain selain +.

Modul 3 (yang mulai dibahas sampai bagian objek radio) membahas objek untuk memasukkan data. Modul 3.1 menyatakan ada beberapa objek yang biasanya terdapat dalam suatu form: Text, Radio, Checkbox, Textarea, dan Select. Objek-objek ini digunakan untuk mengumpulkan input dari user. Modul 3.2 membahas objek Text: cara mengambil nilai dari elemen input teks biasanya lewat document.fform.<nama>.value. Contoh memperlihatkan fungsi tekan() yang mengambil nama dan alamat lalu menaruhnya ke field output onama dan oalamat. Modul 3.3 membahas objek Radio: radio digunakan untuk memilih data, berbentuk array/grup, dan akses satu tombol radio menggunakan radio[indeks]. Materi juga menyebut properti checked bernilai true jika dipilih dan false jika tidak. Selain checked, kamu juga perlu melihat nilai radio tertentu (misalnya value wanita/pria) untuk menentukan output. Materi memberi contoh fungsi radio_box(form) yang memeriksa form.wanita.checked; jika true maka ket='Wanita', selain itu ket='Pria', lalu menampilkan alert. Contoh HTML radio memakai input type="radio" name="wanita" value="wanita" dan tombol confirm yang memanggil radio_box(this.form). Materi juga menyebut reset untuk mengembalikan pilihan.

Catatan untuk tutor: jelaskan konsep interaksi form secara bertahap (text bebas dulu, lalu radio pilihan tunggal, lalu checkbox pilihan ganda) karena siswa perlu membangun mental model bahwa JavaScript membaca properti elemen DOM/form. Tekankan perbedaan .value (data input) dan .checked (status terpilih untuk radio/checkbox). Tekankan juga pentingnya parseFloat dan isNaN pada kasus input angka dari keyboard.
