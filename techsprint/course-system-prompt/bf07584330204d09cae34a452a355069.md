Materi course ini:
Di modul ini kamu belajar HTML mulai dari pengertian, struktur dasar dokumen (HEAD dan BODY), cara menulis tag, hingga HTML entities. Lalu kamu praktek membuat halaman web sederhana lengkap dengan background, warna text, dan hyperlink antar halaman.

Modul ini membahas dasar-dasar HTML yang biasanya dipelajari pada Praktikum Aplikasi IT 1 jurusan Teknik Komputer. Materi dimulai dari pengertian HTML. HTML (Hyper Text Markup Language) adalah bahasa markup yang digunakan untuk membuat halaman web dan menampilkan berbagai informasi di dalam sebuah browser. Konsep HTML berawal dari bahasa markup yang populer di dunia penerbitan dan percetakan bernama SGML (Standard Generalized Markup Language). Seiring waktu, HTML berkembang menjadi standar internet yang luas dipakai untuk menampilkan halaman web. Pada praktiknya, HTML adalah kumpulan kode tag yang menginstruksikan browser bagaimana harus merender tampilan halaman. Karena HTML adalah standar web, dokumen HTML dapat dibuka oleh banyak browser seperti Mozilla Firefox, Microsoft Internet Explorer, Opera, Google Chrome, Safari, dan lain-lain. Saat menulis dokumen HTML, kita bisa menempatkan berbagai jenis konten seperti teks, gambar, suara, dan video. Namun yang membedakan HTML dari dokumen biasa adalah elemen-elemen HTML beserta tag yang menandai struktur serta bagian-bagian tertentu dari dokumen. Dengan tag itulah browser memahami bagian mana yang harus diformat atau ditata.

Setelah pengertian, modul menjelaskan struktur dasar HTML. Secara umum dokumen HTML memiliki pembagian seperti: <HTML>, kemudian bagian header <HEAD>, dan bagian body <BODY>. Bagian header biasanya berisi informasi seperti judul dokumen yang didefinisikan melalui <TITLE> dan ditutup dengan </TITLE>. Setelah header selesai, barulah isi halaman dimulai pada <BODY> ... </BODY>. Seluruh dokumen ditutup dengan </HTML>. Modul juga menekankan bahwa struktur dasar ini penting agar browser bisa membaca dokumen dengan benar dan menampilkan isi sesuai maksud penulis.

Pada bagian elemen HTML, modul menyatakan bahwa elemen HTML terdiri dari dua kategori besar. Pertama, elemen <HEAD> berfungsi untuk memberikan informasi atau mendeklarasikan dokumen tersebut. Kedua, elemen <BODY> berfungsi untuk menentukan bagaimana isi dokumen ditampilkan pada browser. Artinya, bila kamu ingin sesuatu terlihat di halaman (misalnya teks sambutan), letakkan di dalam BODY. Kalau kamu hanya butuh informasi tambahan seperti judul yang muncul di tab browser, gunakan HEAD.

Selanjutnya modul membahas tag. Dalam dokumen HTML, teks dapat memuat instruksi yang ditandai dengan TAG. Tag dinyatakan dengan tanda lebih kecil dan lebih besar (< >). Umumnya tag berupa pasangan: tag awal berfungsi membuka dan tag akhir berfungsi menutup. Tag awal ditulis dengan pola <nama tag>, sedangkan tag akhir ditulis dengan </nama tag>. Modul memberikan contoh tag untuk membuat teks tebal: bila ingin “TAMPIL TEBAL” menjadi tebal, gunakan <b>TAMPIL TEBAL</b>. Penulisan ini berarti <b> mengaktifkan format cetak tebal, teks diikuti di dalamnya, lalu </b> menonaktifkan format tebal agar hanya bagian yang di dalam tag tersebut yang menjadi tebal. Modul menekankan contoh penulisan tag yang benar termasuk bagaimana tag bersarang bisa dilakukan: <tag 1> Teks untuk tag ke 1 <tag 2> Teks untuk tag ke 2 </tag 2> </tag 1>.

Modul kemudian masuk ke HTML entities. Di HTML/XHTML, beberapa karakter bisa dianggap ilegal atau berpotensi disalahartikan jika dituliskan langsung. Contoh penting: karakter lebih besar “>” (dan karakter terkait “<”) bila ditulis langsung bisa membuat browser mengira itu bagian dari tag HTML. Jika kamu menuliskan instruksi seperti “<BR/>” secara biasa, browser dapat menganggap itu sebagai tag sungguhan, sehingga teks “<BR/>” tidak tampil sebagai teks melainkan dijalankan (atau hilang sebagai tampilan string literal). Karena itu HTML menyediakan HTML entities. Modul memberi contoh: untuk menampilkan teks yang berisi simbol “<BR/>” agar simbol < tidak ditafsirkan sebagai tag, gunakan entities seperti &lt;BR/&gt;. Intinya, &lt; digunakan untuk menampilkan karakter “<” dan &gt; untuk menampilkan karakter “>”. Modul juga menampilkan tabel entities yang berisi mapping antara character entity number dan entity name ke karakter yang dihasilkan, menunjukkan bahwa HTML memiliki banyak pilihan entities selain &lt; dan &gt;.

Bagian Modul II memperdalam praktik dasar HTML. Materi pertama adalah membuat dokumen HTML. Modul menjelaskan dokumen HTML dimulai dengan <HTML>, lalu <HEAD> dan <TITLE>. Isi antara <TITLE> dan </TITLE> adalah judul dokumen. Contoh program yang disajikan: <HTML> <HEAD> <TITLE> Web Pertamaku </TITLE> </HEAD> <BODY> Selamat Datang di Web Pertamaku </BODY> </HTML>. Penekanan di sini adalah urutan penulisan tag: HTML menyatukan dokumen, HEAD mendefinisikan informasi seperti judul, BODY menjadi tempat konten yang tampil.

Kemudian modul menjelaskan cara menambahkan komentar. HTML menyediakan komentar dengan penanda <!-- dan -->. Komentar berguna saat pembuat atau orang lain membaca kode untuk memahami bagian-bagian tertentu tanpa mempengaruhi tampilan halaman.

Berikutnya materi background pada halaman web. Modul menjelaskan bahwa background dapat berupa warna atau gambar dan ditambahkan pada tag <BODY>. Untuk background warna gunakan <BODY BGCOLOR="warna"> dan untuk background gambar gunakan <BODY BACKGROUND="nama_gambar.ext">. Modul memberikan contoh program untuk dua skenario tersebut.

Materi berikutnya adalah mengganti warna text. Modul menjelaskan penggunaan tag <FONT COLOR="warna"> untuk mengatur warna teks, diakhiri dengan </FONT>. Contoh program menampilkan beberapa baris teks dengan warna berbeda menggunakan <BR> untuk pindah baris.

Lalu modul membahas hyperlink. Hyperlink dibuat dengan tag <A HREF="nama_file_html_yang_dituju.html">Keterangan link</A>. Modul memberikan contoh dua file: halaman1.html berisi link menuju halaman2.html, dan halaman2.html berisi link kembali ke halaman1.html. Ini mengajarkan konsep navigasi antar halaman.

Setelah hyperlink, modul membahas pemberian warna pada hyperlink. Warna hyperlink diatur dengan atribut pada tag BODY yaitu LINK, ALINK, dan VLINK. LINK mengatur warna link yang belum dikunjungi, ALINK warna saat link sedang diklik, dan VLINK warna link setelah dikunjungi.

Terakhir modul memberikan latihan: buatlah homepage pribadi sederhana sesuai tampilan yang diminta, dengan file index.html sebagai halaman awal serta halaman-halaman lain untuk Sejarah Hidup, Study, Keluarga, dan Cita-cita. Konsep yang harus diterapkan adalah: menu di halaman index.html menggunakan hyperlink yang menuju file-file subhalaman, dan setiap subhalaman berisi konten sesuai judulnya. Secara keseluruhan, modul menggabungkan konsep struktur HTML, tag format, komentar, background, warna text, hyperlink, warna hyperlink, dan penggunaan entities untuk karakter spesial sehingga siswa mampu membangun halaman web dasar yang bisa dinavigasi.
