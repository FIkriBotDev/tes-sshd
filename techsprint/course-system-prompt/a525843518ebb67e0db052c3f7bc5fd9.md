Materi course ini:
Kamu akan paham konsep web server, bedanya HTTP dan HTTPS, lalu belajar langkah setup web server di Debian sampai bisa login phpMyAdmin. Materi ini dibuat seperti panduan praktikum dengan kuis dan latihan interaktif.

Materi ini membahas konsep dasar web server, peranannya dalam mengirim konten web, perbedaan HTTP dan HTTPS, lalu panduan langkah-langkah praktikum setup web server di Debian (TKJ). Struktur materi mencakup: pengertian, fungsi, perbedaan protokol, script/perintah instalasi, serta langkah konfigurasi dan pengujian menggunakan browser. Inti konsep: Web server adalah software yang menerima permintaan HTTP dari client. Saat pengguna mengetik URL pada browser, browser mengirim request ke server; server kemudian merespons dengan mengirim berkas konten web. Konten tersebut bisa berupa teks (HTML), gambar, video, dan lain-lain. Karena itu, web server bertugas mentransfer data atau berkas atas permintaan client melalui HTTP/HTTPS. Penekanan penting: web server bukan sekadar “menampilkan”, tapi menangani komunikasi request-response dengan protokol yang sesuai.

Bagian protokol: HTTP (HyperText Transfer Protocol) dijelaskan sebagai protokol jaringan dan aplikasi untuk sistem informasi terdistribusi. HTTPS (HyperText Transfer Protocol Secure) dijelaskan sebagai protokol yang sama dengan HTTP, namun yang membedakan adalah adanya sistem pengaman. Untuk siswa, tutor bisa jelaskan bahwa HTTP biasanya tidak seaman HTTPS, sedangkan HTTPS menambah keamanan pada proses pengiriman data. Walaupun materi tidak menyebut detail sertifikat TLS, tutor sebaiknya menyederhanakan: HTTPS = HTTP + pengamanan agar data lebih terlindungi saat diakses.

Bagian script dan setup (praktikum): materi memberikan daftar perintah berbasis Debian/Ubuntu untuk menginstal komponen yang diperlukan: Apache2 sebagai web server, MySQL sebagai database, PHP sebagai bahasa/script untuk konten dinamis. Tutor harus menegaskan bahwa sebelum menginstal, pastikan konfigurasi Routing dan DNS Server telah selesai. Ini karena pengujian dilakukan melalui nama domain (contoh tkjclub.info). Jika DNS tidak benar, browser tidak akan menemukan server walaupun service di server sudah terpasang.

Urutan umum sesuai materi: (1) Menambahkan repository dari DVD Debian menggunakan apt-cdrom add (misalnya masukkan DVD-3). (2) apt-get update untuk memperbarui daftar paket. (3) apt-get install -y apache2 untuk menginstal Apache2. (4) apt-get install -y mysql* untuk menginstal paket MySQL, lalu menggunakan DVD Binary-1/2/3 saat diminta (dengan instruksi Force Unmount pada aplikasi virtualisasi). (5) apt-get install -y php7.3* untuk menginstal PHP. (6) apt --fix-broken install ketika terjadi broken packages. (7) apt-get install -y php7.3-zip php7.3-curl untuk paket pendukung (materi menyebut khususnya untuk kebutuhan aplikasi seperti Opencart; tutor bisa menekankan bahwa tidak selalu wajib jika hanya ingin phpMyAdmin, tapi membantu untuk aplikasi berbasis PHP yang memerlukan zip/curl).

Bagian remote akses (SSH): materi memerintahkan edit file /etc/ssh/sshd_config menggunakan nano. Tutor menjelaskan tujuan pengubahan: memberikan izin agar root bisa login sehingga aplikasi remote control seperti WinSCP, PuTTY, FileZilla bisa mengakses server. Script yang dicari adalah PermitRootLogin prohibit-password, lalu diubah menjadi PermitRootLogin yes. Setelah itu simpan dengan Ctrl+X lalu Y lalu Enter. Terakhir restart SSH dengan /etc/init.d/ssh restart dan pastikan hasil OK. Untuk konteks tutor, penting menambahkan bahwa perubahan ini meningkatkan risiko keamanan; namun karena materi latihan fokus pada koneksi remote dalam lingkungan praktik, tutor cukup menekankan tetap hati-hati dan gunakan untuk laboratorium.

Bagian phpMyAdmin: materi menginstruksikan penggunaan WinSCP untuk menyalin file phpMyAdmin dari client ke server pada folder /var/www/html. Setelah file tersalin, install unzip: apt-get install -y unzip. Lalu masuk ke directory /var/www/html (cd /var/www/html) dan mengekstrak arsip phpMyAdmin dengan unzip php (dengan Tab untuk melengkapi nama file). Setelah unzip, folder phpMyAdmin-5.0.2-all-languages diganti namanya menjadi phpmyadmin menggunakan mv ... phpmyadmin. Kemudian set permission dengan chmod 755 -R /var/www/html/phpmyadmin. Tutor bisa menekankan kenapa permission penting: agar Apache2 bisa membaca file phpMyAdmin dan browser bisa mengakses halaman.

Bagian database untuk admin phpMyAdmin: materi memberi perintah mysqladmin -u root password 12345678, lalu restart MySQL /etc/init.d/mysql restart. Tutor perlu mengaitkan ini: saat login phpMyAdmin, kredensial yang digunakan harus sesuai pengaturan password admin root yang dibuat/diperbaharui.

Pengujian service: materi menyarankan instal nmap dengan apt-get install -y nmap, lalu cek port aktif menggunakan nmap localhost. Di materi, contoh port yang harus terdaftar: http port 80 untuk Apache2, dan mysql port 336 untuk MySQL. Tutor bisa mengajarkan bahwa nmap digunakan untuk memverifikasi service benar-benar listening pada port yang sesuai.

Pengujian via browser: setelah service siap, buka browser dan ketik nama domain (contoh tkjclub.info). Jika berhasil tampil “Apache2 Debian Default Page” yang menandakan Apache2 berjalan. Lalu buka tab baru dengan tkjclub.info/phpmyadmin. Jika berhasil muncul halaman login phpMyAdmin. Login menggunakan username root dan password 12345678, lalu klik Go. Jika halaman manajemen database tampil, berarti konfigurasi web server dan database terhubung dan phpMyAdmin dapat dijalankan.

Kesimpulan materi: jika seluruh step dilakukan dan login berhasil, konfigurasi WEB Server dinyatakan selesai dan sukses. Tutor bisa menutup dengan mengaitkan kembali konsep inti: web server menerima HTTP request, Apache2 menyiapkan layanan web, PHP menyiapkan konten dinamis, MySQL menyediakan data, dan phpMyAdmin adalah antarmuka untuk mengelola database.
