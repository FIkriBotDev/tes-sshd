Materi course ini:
Kamu akan belajar membangun server Debian 10 (Buster) di VirtualBox, mulai dari struktur Linux, instalasi, cloning VM, sampai konfigurasi jaringan dan fondasi perintah dasar. Materinya juga mengarahkan ke layanan server populer seperti web (LAMP/LEMP), DNS, CA, mail, file sharing, FTP, dan monitoring.

Materi ini adalah panduan Administrasi Debian 10 Server yang membimbing peserta dari pemahaman dasar Linux sampai praktik instalasi dan konfigurasi server menggunakan VirtualBox. Bagian awal membahas pengenalan Linux: Linux merupakan keluarga sistem operasi bebas dan sumber terbuka yang dibangun di atas kernel Linux. Kernel ini pertama kali dikembangkan oleh Linus Torvalds pada tahun 1991. Linux dirilis di bawah lisensi GNU GPL v2. Penting dipahami bahwa secara teknis kata “Linux” bisa merujuk pada kernel-nya saja, namun agar menjadi sistem operasi utuh, kernel tersebut dilengkapi komponen perangkat lunak dari proyek GNU. Karena itulah istilah yang lebih tepat adalah GNU/Linux: kernel Linux + komponen GNU (misalnya utilitas dan tools) sehingga membentuk sistem operasi lengkap.

Materi juga menjelaskan bahwa Linux bukan hanya untuk server. Saat ini Linux digunakan luas untuk desktop dan perangkat smartphone seperti Android, serta perangkat embedded seperti router, televisi, dan bahkan kendaraan (contoh Tesla). Keunikan Linux adalah hasil kolaborasi perangkat lunak bebas dan open source, di mana kode sumber bisa digunakan, dimodifikasi, dan didistribusikan baik komersial maupun non-komersial sesuai ketentuan lisensi. Tutor dapat menekankan bahwa konsep open source ini penting untuk cara kerja komunitas Linux: peserta belajar karena ekosistemnya besar, dokumentasinya luas, dan banyak contoh.

Selanjutnya masuk ke struktur direktori Linux (hirarki filesystem). Tutor perlu menjelaskan fungsi direktori yang sering muncul dalam praktik server. Direktori / adalah root, direktori dasar. /bin berisi file yang dapat dieksekusi. /boot berisi file untuk proses booting. /dev berisi device files (contoh penyimpanan seperti /dev/sda). /etc menyimpan konfigurasi sistem. /home adalah direktori home untuk user. /lib adalah library yang berhubungan dengan kernel. /media berisi media yang terpasang (cdrom, flashdisk, harddisk eksternal, dll). /mnt dipakai untuk pengaitan sistem sementara. /opt adalah tempat paket aplikasi tambahan. /proc adalah filesystem virtual yang berisi dokumentasi kernel dan status proses. Selain itu, materi menyebut /root sebagai home untuk user root (bukan di /home/root). /sbin berisi biner esensial untuk menjalankan dan memperbaiki sistem, biasanya dipakai administrator; contoh yang disebut materi mencakup fastboot, halt, fdisk, fsck, getty, reboot, route, swapon, swapoff, mkfs, dan lainnya. /srv menyimpan data untuk layanan (contoh /srv/ftp, /srv/www). /sys berisi informasi perangkat keras seperti yang terlihat dari Linux. /tmp untuk file sementara yang biasanya terhapus saat restart. /usr berisi file yang dibagi untuk semua user sistem dan umumnya read-only. /var berisi file-file variable, contohnya log, mail, print, dan lainnya. Karena peserta masih pemula, tutor sebaiknya menekankan cara berpikir: jika ingin cari konfigurasi, cek /etc; jika cari data log dan yang sering berubah, cek /var; jika cari file sementara, cek /tmp; jika butuh executables umum, cek /bin dan /usr/bin (walau di materi hanya menyebut /bin dan /usr, tutor bisa mengaitkan).

Bagian berikutnya adalah “distro Linux”. Materi menjelaskan distro Linux adalah sistem operasi yang dibangun dari kernel Linux dengan penambahan modul, aplikasi, service, atau package lain agar menjadi sistem yang spesifik sesuai tujuan pengembang. Distro adalah singkatan dari Linux DISTRibutiOn. Contoh distro yang diberikan: Debian, Ubuntu, Fedora, Red Hat. Materi fokus pada Debian 10 (Buster) dan mengarahkan peserta untuk mendownload ISO Debian dari situs resmi Debian installer pada rilis Buster.

Lalu masuk BAB 2: instalasi dan konfigurasi server Debian 10.x (Buster). Pertama, materi menjelaskan topologi praktik menggunakan 3 virtual machine Debian di VirtualBox. Tutor perlu menerangkan bahwa VirtualBox adalah software virtualisasi untuk menjalankan OS “tambahan” di dalam OS utama. RAM VirtualBox dialokasikan dari RAM laptop/PC, jadi performa bergantung pada RAM yang tersedia. Materi merekomendasikan minimal RAM laptop 4GB. Contohnya, jika dibuat 3 VM Debian dengan RAM 512 MB, total RAM terpakai 1,5 GB; namun untuk instalasi awal, materi mencontohkan RAM 1GB.

Langkah membuat VM dan instalasi Debian di VirtualBox dijelaskan secara urut. Tutor harus membimbing peserta: buka VirtualBox → New → isi nama → next → atur RAM → create a virtual harddisk now. Pilih VDI dan Dynamic Allocated. Buat harddisk minimal 8GB. Setelah VM dibuat, masuk ke Settings → Storage. Di Controller: IDE, pilih Empty lalu pilih disk icon dan masukkan file ISO Debian. Klik Start untuk menjalankan VM dan lakukan instalasi. Proses instalasi mencakup pemilihan bahasa (English), pemilihan Country/region (karena Indonesia tidak ada di daftar langsung, peserta memilih Other → Asia → Indonesia), keyboard layout (American English), pengaturan hostname (contoh “debian”), domain name (boleh dikosongkan karena nanti dikonfigurasi), set password user root, lalu membuat user baru: nama lengkap, username, dan password. Tentukan zona waktu; materi memilih Western untuk WIB. Partisi dilakukan menggunakan Guided – use entire disk, dengan opsi All files in one partition (recommended untuk pemula). Pilih Finish partitioning and write changes to disk dan konfirmasi Write changes to disks? Yes. Selanjutnya menunggu instalasi base system selesai.

Untuk repo, materi menampilkan pilihan “Use a network mirror?”. Jika ingin menambah repo, pilih Yes dan pilih Indonesia. Materi juga menjelaskan pilihan survei penggunaan paket: Participate in the package usage survey? dipilih No. Lalu pilih paket yang akan diinstal. Untuk server berbasis CLI, centang SSH Server dan standard system utilities. Jika server berbasis GUI, bisa centang Debian desktop environment, namun dalam materi konteksnya server. Kemudian pada pengaturan GRUB boot loader, pilih Install the GRUB boot loader to master boot record? Yes, dan pilih perangkat target /dev/sda. Setelah selesai, pilih Continue dan restart. Tutor perlu memandu peserta untuk login setelah reboot (menggunakan user root dan password yang diinput saat instalasi).

Setelah VM terpasang, materi masuk ke setup topologi di VirtualBox dengan fokus pada cloning VM. Tutor perlu menjelaskan konsep cloning: menduplikasi VM yang sudah ada menjadi VM yang berbeda. Karena topologi butuh 3 VM Debian (Router, Server1, Server2), maka digunakan cloning. Materi memilih linked clone berbasis VM Debian yang sudah diinstal agar hemat storage dibanding clone penuh. Langkahnya: siapkan base VM, ubah RAM base VM jadi 512MB melalui Settings > System > RAM. Kemudian untuk Router Debian: klik kanan base VM → Clone → ubah nama menjadi Debian-Router → MAC Address Policy pilih Generate new MAC addresses → pilih linked clone → Clone. Lakukan hal sama untuk Server1 dan Server2 dengan nama dan linked clone, serta MAC address policy generate new.

Konfigurasi network adapter dijelaskan untuk menyesuaikan topologi. Tutor sebaiknya mengajari peserta terlebih dahulu mengatur alamat IP Host-Only Adapter melalui File → Host Network Manager. Jika IP host-only yang dipakai (misal 192.168.101.x) bentrok dengan LAN, maka ganti ke IP yang berbeda. Pastikan DHCP Server di host-only tidak dicentang supaya konfigurasi IP dilakukan manual sesuai rencana topologi. Setelah itu, untuk Router Debian: pilih Settings → Network. Adapter 1 bisa dipilih Bridged Adapter atau NAT (pilih salah satu sesuai kebutuhan akses jaringan). Lalu Adapter 2: enable dan pilih Host-Only Adapter. Untuk Server1 dan Server2, pada Adapter 1 pilih Host-only Adapter. Tutor perlu menegaskan tujuan pemisahan ini: router menghubungkan dua sisi jaringan (internal host-only dan sisi lain melalui bridged/NAT), sedangkan server cukup ada di jaringan internal host-only agar konektivitas bisa diuji dalam topologi.

Materi juga mulai BAB 2 pada subbagian “Konfigurasi Dasar Debian” dan memperkenalkan perintah dasar Linux. Tutor perlu menjelaskan bentuk shell prompt: username@hostname: ~ $ untuk user biasa, dan root@hostname:~# untuk root. Simbol $ menunjukkan user biasa, # menunjukkan root. Tanda ~ menunjukkan kamu berada di folder home. Perintah su digunakan untuk beralih ke root dari user biasa. Perintah whoami untuk mengetahui user yang sedang digunakan. Perintah ls untuk melihat isi folder; contoh ls Downloads/ untuk melihat isi folder Downloads. Variasi ls -l untuk melihat detail termasuk permission; dan ls -a untuk menampilkan file/folder hidden.

Walaupun materi yang kamu kirim berhenti detail di bagian perintah ls -a, daftar isi PDF menegaskan bab-bab lanjutannya mencakup: konfigurasi hostname dan hosts, repository, sudo, remote login SSH, konfigurasi Debian-router, DNS caching & forwarding serta DNS authoritative, pembuatan Certificate Authority (CA), konfigurasi web dan database melalui LAMP dan LEMP, konfigurasi mail server dan webmail, file sharing (Samba dan NFS), FTP server, serta monitoring server. Tutor sebaiknya mengaitkan bahwa semua bagian lanjutan biasanya butuh fondasi: pemahaman filesystem (/etc, /var, etc.), pemahaman jaringan (adapter, IP, host-only), serta kemampuan menjalankan perintah dasar Linux dengan benar (berpindah user, mengecek isi folder, dan membaca permission).
