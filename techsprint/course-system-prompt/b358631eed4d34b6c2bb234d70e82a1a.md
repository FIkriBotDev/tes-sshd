Materi utama:
Lab ini membahas proses mengevaluasi versi pilot agen AI untuk platform e-commerce TechMart menggunakan MLflow. Fokus evaluasi mencakup kualitas rekomendasi produk, akurasi respons agen, serta dampaknya pada pengalaman pengguna secara keseluruhan.

Agar lab dapat dijalankan, peserta perlu menyiapkan prasyarat seperti akun GitHub, akun Replicate, dan Google Colab. Replicate digunakan untuk menjalankan model AI (misalnya IBM Granite) di cloud tanpa perlu perangkat keras khusus, sedangkan token Replicate berperan sebagai kunci autentikasi yang aman untuk integrasi dari lingkungan Colab.

Selanjutnya peserta menginisialisasi agen AI beserta alat (tools) yang dapat digunakan agen untuk menjawab permintaan pengguna. Agen akan memilih alat yang sesuai berdasarkan prompt, mengeksekusi kueri ke tool tersebut, menerima hasil, lalu menyusun respons. Di bagian akhir lab, peserta mengevaluasi trajektori dan respons akhir agen, untuk menentukan apakah agen siap disebarkan secara penuh.

Materi lab ini menjelaskan bagaimana mengevaluasi kinerja agen AI untuk kebutuhan e-commerce TechMart menggunakan MLflow. Secara konsep, evaluasi diarahkan pada kualitas agen dalam konteks pengalaman pengguna: apakah agen mampu memberi rekomendasi produk yang relevan, menjawab pertanyaan dengan akurat, dan membantu navigasi katalog secara efektif. Bila agen gagal—misalnya rekomendasi tidak relevan atau tidak membantu menemukan produk—pengguna cenderung meninggalkan situs. Selain itu, ketidakakuratan atau inkonsistensi detail produk seperti harga, ketersediaan stok, atau informasi lain bisa menurunkan kepercayaan pengguna, sehingga kinerja agen perlu diukur secara terstruktur.

Lab menetapkan peran peserta sebagai spesialis AI dalam tim evaluasi. Peserta tidak hanya diminta menjalankan notebook, tetapi juga memahami alasan setiap komponen lingkungan yang harus disiapkan. Pertama, peserta menyiapkan akun GitHub. GitHub berfungsi sebagai platform pengembangan: menyimpan dan mengelola kode, serta mendukung kolaborasi melalui kontrol versi. Dalam lab ini GitHub digunakan untuk mempermudah proses pendaftaran ke Replicate (melalui mekanisme “Authorize replicate”), dan juga menjadi sumber repositori notebook yang akan dimuat ke Google Colab.

Kedua, peserta membuat akun Replicate. Replicate menyediakan ekosistem berbasis cloud untuk menjalankan model AI tanpa memerlukan infrastruktur perangkat keras yang rumit. Bagian terpenting pada Replicate adalah pembuatan token API. Token API adalah kunci akses aman yang dipakai untuk autentikasi saat Colab menjalankan kode yang berinteraksi dengan Replicate API. Materi menekankan agar token disimpan dengan aman karena akan digunakan untuk mengizinkan notebook mengeksekusi model dari akun peserta. Selain token, materi juga menyebut perlunya kredit Replicate agar lab tidak terganggu; peserta dapat mengklaim kredit gratis senilai $0,50 melalui tautan undangan.

Ketiga, peserta mendaftar Google Colab. Colab adalah platform notebook cloud yang memungkinkan eksekusi kode untuk pembelajaran mesin dan AI. Materi menekankan langkah keamanan: token Replicate tidak langsung ditulis di notebook, melainkan disimpan ke dalam Secrets di Colab. Nama secret yang diminta adalah REPLICATE_api_token. Dengan demikian, runtime dapat mengambil token secara aman pada saat notebook dijalankan, mengurangi risiko kebocoran kredensial.

Setelah lingkungan siap, materi masuk ke inisialisasi agen AI dan alat. Dalam kerangka agen AI, “tools” dipahami sebagai fungsi yang dapat dipanggil agen untuk membantu tugas-tugas tertentu, contohnya mencari informasi, memeriksa stok produk, atau melihat data. Pengguna memberikan prompt yang menentukan tool mana yang boleh diakses agen. Agen kemudian melakukan proses: memilih tool yang relevan, mengirim kueri ke tool tersebut, menerima hasil, dan menyusun respons akhir. Dengan cara ini, agen bisa menghasilkan jawaban yang lebih informatif dan kontekstual, karena respons disusun berdasarkan data dari tool, bukan hanya generasi teks statis.

Materi juga membimbing peserta menjalankan notebook melalui Colab: peserta membuka Colab, memilih untuk membuka notebook dari GitHub menggunakan URL repositori yang disediakan, kemudian memilih file agent-eval.ipynb. Selanjutnya peserta menghubungkan notebook ke hosted runtime menggunakan opsi Connect to a hosted runtime. Poin penting bagi tutor: kode dieksekusi di environment cloud, bukan pada mesin lokal peserta, sehingga perhitungan dan pemanggilan API berjalan di sisi server Colab.

Bagian evaluasi menargetkan dua dimensi utama: trajektori dan respons akhir. Trajektori mengacu pada alur proses internal agen sebelum output disajikan—misalnya urutan tool yang dipanggil dan bagaimana agen menggunakan hasil tool untuk merumuskan jawaban. Respons akhir adalah output yang diterima pengguna. Evaluasi trajektori memungkinkan penguji mengetahui apakah agen bekerja secara logis dan konsisten (misalnya memanggil tool yang sesuai dan menggunakan hasilnya dengan benar), sedangkan evaluasi respons akhir memvalidasi apakah output benar-benar membantu pengguna dan memberikan rekomendasi yang relevan.

Walaupun materi yang diberikan memuat langkah-langkah inisialisasi dan prasyarat secara rinci, inti besarnya adalah pendekatan pengukuran: menggunakan MLflow untuk melacak, mengevaluasi, dan memvisualisasikan kinerja agen. Hasil evaluasi digunakan untuk keputusan kesiapan deployment penuh: apakah agen sudah layak dirilis atau masih memerlukan perbaikan pada aspek rekomendasi, akurasi respons, dan kualitas pengalaman pengguna. Dengan kata lain, lab mengajarkan pipeline end-to-end dari penyiapan kredensial dan runtime, inisialisasi agen dengan tools, hingga evaluasi berbasis trajektori dan respons menggunakan prinsip observabilitas melalui MLflow.
