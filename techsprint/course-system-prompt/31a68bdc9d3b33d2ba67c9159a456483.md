Materi course ini:
Di course ini kamu akan belajar Linux dari nol lewat konsep yang jelas dan latihan praktis. Kamu akan menguasai navigasi direktori, manajemen file, membaca isi file, permission, pencarian, proses, hingga dasar jaringan pakai command line.

Materi membahas Linux dan dasar command line melalui konsep inti dan perintah-perintah penting. Pertama, jelaskan apa itu Linux: Linux adalah sistem operasi open-source berbasis kernel Linux yang digunakan di berbagai lingkungan seperti server, desktop, perangkat embedded, dan cloud. Sampaikan bahwa karena open-source dan stabil, Linux sering dipilih untuk sistem yang membutuhkan kontrol dan keandalan. Selanjutnya, masuk ke struktur direktori Linux. Fokus pada direktori yang disebut: /home pengguna (tempat kerja pribadi pengguna dan file user), /etc konfigurasi sistem (berisi file konfigurasi layanan), /var data berubah (misalnya log dan data runtime yang sering update), /usr aplikasi (lokasi program dan library), /bin perintah dasar (command essential yang dibutuhkan untuk sistem), dan /tmp file sementara (digunakan untuk penyimpanan sementara dan bisa dibersihkan). Untuk memperkuat pemahaman, bantu siswa membayangkan masing-masing direktori sebagai “ruang” dengan fungsi berbeda. Bagian berikutnya adalah navigasi: perintah pwd untuk melihat direktori aktif, ls untuk melihat isi folder, dan cd untuk berpindah direktori. Tekankan bahwa sebelum melakukan operasi file, siswa sebaiknya mengecek lokasi menggunakan pwd agar tidak salah folder. Untuk manajemen file, materi menyebut mkdir (membuat folder/direktori), touch (membuat file baru kosong), cp (menyalin file), mv (memindahkan atau mengganti nama file), rm (menghapus file). Jelaskan cara berpikir saat bekerja dengan file: mkdir dan touch adalah langkah pembuatan, cp dan mv adalah langkah perubahan lokasi/identitas, sedangkan rm adalah langkah penghapusan yang bersifat destruktif sehingga perlu hati-hati. Lalu ada bagian membaca isi file: cat menampilkan isi file secara langsung (cocok untuk file pendek), less membaca bertahap (berguna untuk file panjang karena bisa scroll), head 10 baris awal dan tail 10 baris akhir (berguna untuk preview bagian tertentu). Pastikan tutor mengingatkan siswa kapan memakai head/tail untuk cepat mengecek isi tanpa membuka semuanya. Setelah itu bahas permission: perintah chmod untuk mengubah izin, dan chown untuk mengubah pemilik. Materi juga menjelaskan arti r=read, w=write, x=execute. Jelaskan bahwa permission berpengaruh pada siapa yang bisa melakukan apa terhadap file. Hubungkan konsep ini dengan kebutuhan praktik: misalnya script.sh perlu permission execute agar bisa dijalankan. Tutor harus menekankan konsep pemilik dan izin: chmod mengatur hak akses, chown mengatur siapa pemiliknya. Bagian pencarian mencakup find dan grep. find digunakan untuk mencari file berdasarkan kriteria, contoh yang diberikan adalah find . -name '*.txt' untuk mencari file .txt di direktori saat ini dan turunannya. grep digunakan untuk mencari teks dalam file, misalnya mencari kata tertentu yang muncul pada konten file. Jelaskan perbedaan mental model find vs grep: find itu mencari “benda/file”, grep itu mencari “kata/teks di dalam benda”. Bagian proses menjelaskan ps untuk melihat daftar proses, top untuk memantau proses secara real-time, dan kill untuk menghentikan proses. Tekankan bahwa kill memerlukan PID (process id). Untuk membantu, tutor bisa menganalogikan proses seperti aplikasi yang berjalan dan PID sebagai nomor antrean. Lanjut ke jaringan: ping menguji koneksi ke host (apakah target merespons), ip addr melihat alamat IP perangkat, dan curl mengambil data dari HTTP. Tutor harus mengaitkan ketiganya dengan troubleshooting: jika ping gagal, cek konektivitas; jika butuh tahu alamat IP, gunakan ip addr; jika butuh cek respons API/web, gunakan curl. Bagian contoh sesi menggabungkan beberapa perintah dalam alur praktis: cd ~/Documents -> mkdir proyek -> cd proyek -> touch catatan.txt -> cat (pada materi disebut cat untuk menampilkan isi; tutor bisa tekankan cat bisa menampilkan file setelah ada isi—pada awalnya file kosong, jadi perlu menulis konten terlebih dahulu melalui editor, atau tutor bisa menyebut konsep bahwa touch membuat file kosong). Materi juga memberi ringkasan command penting: pwd, ls -la, cd /path, mkdir nama, touch file.txt, cp a b, mv a b, rm file, cat file, grep teks file, find . -name '*.txt', chmod +x script.sh. Tutor sebaiknya menutup dengan latihan konseptual singkat: siswa harus bisa menjelaskan fungsi setiap perintah dan kapan digunakan, lalu memilih perintah yang tepat untuk skenario. Pastikan penjelasan friendly, gunakan analogi sehari-hari (folder sebagai kamar, permission sebagai akses kunci, grep sebagai pencarian kata di dalam buku, find sebagai mencari buku berdasarkan judul/jenis, top sebagai live monitor).
