Materi course ini:
Belajar dasar pemrograman Python mulai dari pengenalan, variabel & tipe data, operator, percabangan, loop, struktur data, sampai fungsi. Kamu juga akan praktik langsung lewat playground biar makin cepat paham.

Materi ini membahas fondasi pemrograman Python untuk pemula, dari pengenalan bahasa, konsep dasar variabel dan tipe data, operator, struktur kontrol percabangan (if/elif/else), perulangan (for/while), struktur data (list/tuple/dictionary), hingga fungsi (function) menggunakan def dan return. Tutor sebaiknya memandu peserta didik dengan gaya yang ramah seperti belajar bareng teman: mulai dari memahami “apa itu Python”, lalu langsung menghubungkannya ke contoh kode sederhana, dan mengulang latihan dengan mengubah nilai agar peserta merasakan efeknya. Tutor juga perlu menekankan bahwa Python dibuat agar mudah dibaca dan dipelajari, sehingga peserta tidak terlalu takut pada sintaks di awal.

Bagian 1: Pengenalan Python. Tutor menjelaskan bahwa Python adalah bahasa pemrograman tingkat tinggi yang didesain agar mudah dibaca. Disebut juga bahwa Python diciptakan oleh Guido van Rossum pada tahun 1991. Jelaskan kenapa Python populer: (1) sintaksnya sederhana dan mirip bahasa Inggris sehingga pembaca pemula lebih mudah memahami maksud kode, (2) komunitas besar dan pustaka/library lengkap yang membuat banyak masalah bisa diselesaikan cepat, (3) multi-platform (Windows, Mac, Linux) sehingga peserta tidak terikat satu sistem. Tutor bisa menegaskan bahwa belajar Python ibarat membuka pintu ke banyak bidang: Data Science, AI, dan pengembangan web.

Bagian 2: Variabel dan Tipe Data. Tutor mengajarkan bahwa variabel itu wadah untuk menyimpan data. Peserta tidak perlu mendeklarasikan tipe data secara eksplisit karena Python bersifat dinamis (tipe ditentukan berdasarkan nilai). Tipe dasar yang harus dipahami: Integer untuk bilangan bulat (contoh 10, -5), Float untuk bilangan desimal (3.14, 2.0), String untuk teks diapit kutip ("Halo Dunia"), dan Boolean untuk logika True/False. Materi juga memberi contoh variabel: nama = "Budi", umur = 20, tinggi = 175.5, is_student = True. Tutor perlu menekankan output bisa dibuat dengan print, termasuk format menggunakan f-string seperti print(f"Nama: {nama}, Umur: {umur}") agar peserta melihat cara memasukkan variabel ke teks.

Bagian 3: Operator Dasar. Tutor menerangkan bahwa operator melakukan operasi pada variabel dan nilai. Operator yang ada di materi: + penjumlahan, - pengurangan, * perkalian, / pembagian (contoh 5 / 2 = 2.5), dan ** perpangkatan (contoh 5 ** 2 = 25). Tutor sebaiknya memberi penekanan khusus pada perpangkatan karena operator ini berbeda dari banyak bahasa lain yang mungkin memakai pow(). Di kelas, tutor bisa meminta peserta memprediksi hasil terlebih dahulu sebelum menjalankan kode.

Bagian 4: Struktur Kontrol Percabangan. Tutor menjelaskan penggunaan if, elif, else untuk membuat keputusan. Materi contoh grade: nilai = 85; jika nilai >= 90 maka print "Grade: A"; elif nilai >= 75 print "Grade: B"; else print "Grade: C". Tutor sebaiknya menekankan pentingnya urutan kondisi dari yang paling besar ke yang lebih kecil agar logika benar, dan juga pentingnya indentasi karena Python menggunakan whitespace untuk blok kode. Tutor bisa menambahkan pertanyaan reflektif: “Kalau nilai 90, masuk kategori apa? Kalau 74, masuk mana?”

Bagian 5: Perulangan (Loops). Tutor menjelaskan dua jenis utama: for dan while. Untuk for, materi menunjukkan: for i in range(5): print(f"Iterasi ke-{i}"). Tutor perlu menjelaskan bahwa range(5) menghasilkan angka 0 sampai 4, sehingga iterasi ada 5 kali. Untuk while, materi menunjukkan: count = 0; while count < 3: print("Halo!"); count += 1. Tutor perlu mengingatkan bahwa while butuh perubahan kondisi (count += 1) supaya loop berhenti; kalau tidak, program bisa berjalan terus (infinite loop). Tutor bisa mengajak peserta mengubah batas atau nilai awal count untuk melihat dampak.

Bagian 6: Struktur Data List, Tuple, Dictionary. Tutor menjelaskan bahwa struktur data digunakan untuk menyimpan koleksi data dalam satu variabel. List: terurut dan bisa diubah, contoh buah = ["Apel", "Jeruk"]. Tuple: terurut tetapi tidak bisa diubah, contoh koordinat = (10, 20). Dictionary: pasangan kunci dan nilai, contoh user = {"nama": "Andi", "usia": 25}. Tutor bisa memberi analogi: list seperti daftar, tuple seperti stiker yang tidak boleh ditempel ulang/diubah, dictionary seperti formulir dengan label kunci (nama/usia) dan isinya.

Bagian 7: Fungsi (Function). Tutor menjelaskan bahwa fungsi adalah blok kode yang berjalan hanya saat dipanggil. Materi memberi contoh def sapa(nama): return f"Halo, {nama}! Selamat belajar Python." lalu pesan = sapa("Andi") dan print(pesan). Tutor perlu menekankan dua hal: def untuk mendefinisikan fungsi, return untuk mengembalikan hasil. Jelaskan manfaat fungsi: membuat kode rapi, bisa dipakai ulang, dan memudahkan debugging.

Bagian 8: Penutup. Tutor menegaskan bahwa Python sangat luas dan materi ini adalah fondasi. Langkah selanjutnya yang disebut: mempelajari library seperti NumPy (matematika), Pandas (data), dan Django (web). Tutor bisa mengarahkan peserta ke ide: “setelah kamu kuat di dasar, library akan membuat kamu jauh lebih cepat menyelesaikan proyek nyata.”

Selama mengajar, tutor sebaiknya: (1) menautkan konsep dengan contoh kode pendek, (2) meminta peserta memodifikasi nilai agar memahami perubahan output, (3) menggunakan bahasa sederhana dan ramah, (4) menekankan kebiasaan indentasi benar untuk if/while, dan (5) memastikan peserta memahami hubungan antar konsep: variabel dan tipe data adalah “bahan”, operator adalah “alat”, if/loop adalah “cara mengambil keputusan dan pengulangan”, struktur data adalah “wadah kumpulan”, dan fungsi adalah “resep yang bisa dipakai ulang”.
