Materi course ini:
Belajar konsep FTP Server dan cara menyalakannya di XAMPP sampai bisa diuji lewat FileZilla. Kamu akan paham port 21, cara memastikan layanan ProFTPD berjalan, dan izin folder agar upload/download sukses.

Materi PDF ini membahas cara setup FTP Server menggunakan XAMPP pada konteks perangkat yang menjalankan XAMPP (umumnya Linux/lingkungan yang memiliki path /opt/lampp/htdocs seperti pada materi). Bagian awal menjelaskan konsep FTP Server: FTP adalah protokol standar untuk mentransfer file antar komputer di jaringan (contoh: internet atau jaringan lokal). FTP Server adalah komponen/perangkat lunak/komponen layanan yang menyediakan fasilitas upload (mengunggah) dan download (mengunduh) file antara komputer klien dan server melalui koneksi jaringan. Jadi, peran server adalah “tempat” file dikelola, sedangkan klien menggunakan software client (misalnya FileZilla) untuk terhubung.

Setelah konsep dipahami, materi masuk ke langkah instalasi dan aktivasi FTP Server menggunakan XAMPP. Langkah 1: pengguna diminta membuka browser dan mengunduh XAMPP dari situs resmi. Di sini tujuannya memastikan instalasi benar dari sumber tepercaya dan versi yang sesuai dengan sistem operasi. Langkah 2: setelah file installer terunduh, pengguna menjalankan instalasi dari terminal menggunakan perintah seperti ./nama_file_installer.run. Ini memulai proses instalasi XAMPP. Langkah 3: pengguna menunggu sampai instalasi selesai, lalu memastikan tidak muncul pesan kesalahan. Penekanan “tidak ada pesan kesalahan” penting karena jika ada error saat instalasi, service yang diperlukan (termasuk ProFTPD) bisa gagal berjalan.

Langkah 4 adalah mengaktifkan FTP server dengan mengklik tombol Start pada service ProFTPD di panel XAMPP. ProFTPD adalah implementasi server FTP yang terpasang/terintegrasi dalam ekosistem XAMPP. Jika ProFTPD tidak di-start, maka FTP server tidak akan membuka layanan, sehingga koneksi dari client akan gagal.

Langkah 5 adalah verifikasi bahwa FTP server benar-benar aktif. Materi menyarankan melakukan pemindaian port ke localhost menggunakan nmap pada tcp 21. Konsep penting di sini: FTP standar memakai port 21, sehingga saat service FTP berjalan, port tersebut akan terdeteksi sebagai terbuka. Jika port 21 tidak terbuka, berarti layanan FTP belum aktif atau ada masalah konfigurasi/firewall.

Langkah 6 mengatur izin direktori agar FTP bisa melakukan operasi file. Materi menyebut direktori XAMPP yaitu /opt/lampp/htdocs dan memberikan izin read, write, dan execute menggunakan perintah chmod 777. Inti konsepnya adalah permission (hak akses) pada sistem operasi: server perlu izin untuk membaca file yang akan diunduh dan menulis file yang akan diunggah. Tanpa izin yang cukup, meski ProFTPD aktif, transfer file bisa gagal.

Langkah 7 adalah pengujian koneksi menggunakan software FileZilla. Pengguna diminta mengakses FTP server XAMPP dengan memasukkan IP server, username, password, serta port 21. Setelah data diisi, klik Quickconnect. Jika koneksi berhasil, biasanya pengguna akan bisa melihat daftar folder dan melakukan upload/download. Jika gagal, troubleshooting umumnya mengarah ke (1) ProFTPD belum start, (2) port 21 tidak terbuka, (3) kredensial salah, atau (4) permission folder belum sesuai.

Untuk AI tutor, berikan penekanan pada hubungan sebab-akibat: “Start ProFTPD” membuat layanan FTP berjalan; “nmap port 21” memastikan layanan benar-benar listening; “chmod izin pada htdocs” memastikan sistem file dapat diakses oleh FTP; dan “FileZilla Quickconnect” memvalidasi dari sisi user/client bahwa upload-download berfungsi. Jelaskan juga istilah upload/download, port, dan alasan folder htdocs dipakai sebagai lokasi file. Tutor sebaiknya mengajak siswa membayangkan alur kerja: server menunggu di port 21, client menghubungi port itu, lalu izin folder menentukan apakah file dapat dipindahkan. Contoh troubleshooting singkat bisa diberikan: jika port closed, cek service; jika port open tapi login gagal, cek username/password; jika login sukses tapi upload gagal, cek izin folder.
