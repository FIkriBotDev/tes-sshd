Materi utama:
Web server adalah software yang memberikan layanan berbasis data dengan menerima permintaan HTTP dari client. Pada konfigurasi ini, web server bertugas mentransfer berkas (teks, gambar, video, dll.) melalui protokol HTTP/HTTPS agar konten web dapat diakses oleh pengguna lewat browser.

Materi membahas pembuatan dan konfigurasi web server pada sistem Debian menggunakan Apache2, MySQL, dan PHP, sekaligus integrasi phpMyAdmin agar pengelolaan database dapat dilakukan lewat tampilan web. Di bagian awal materi dijelaskan konsep dasar web server: web server adalah software yang menerima permintaan HTTP dari client. Saat client (misalnya browser) mengakses sebuah domain, permintaan dikirim menggunakan HTTP. Web server kemudian mengirimkan respons berupa file/konten yang diminta. Konten tersebut dapat berupa teks, gambar, video, atau jenis berkas lainnya yang disediakan oleh server. Karena web server bekerja berbasis pertukaran data melalui protokol jaringan, materi juga menjelaskan fungsi transfer data melalui HTTP/HTTPS.

Pada materi selanjutnya dijelaskan perbedaan HTTP dan HTTPS. HTTP adalah protokol HyperText Transfer Protocol yang digunakan dalam sistem informasi terdistribusi. HTTPS adalah versi yang sama namun aman (secure), yaitu menggunakan sistem pengaman. Secara implementasi, materi menekankan bahwa saat pengguna mengakses layanan web, komunikasi berlangsung melalui protokol tersebut; pada konfigurasi web server, yang penting adalah server dapat mengirimkan halaman sesuai permintaan alamat domain.

Bagian paling besar materi adalah langkah-langkah konfigurasi. Pertama, tutor perlu menekankan prasyarat jaringan: konfigurasi router server dan DNS server harus sudah selesai dan berhasil. Tanpa DNS/routing yang benar, domain yang diketik di browser tidak akan mengarah ke server sehingga pengecekan hasil konfigurasi gagal.

Setelah prasyarat jaringan, materi mengarahkan penggunaan media instalasi Debian (DVD/ISO). Tutor perlu mengajarkan kapan dan DVD mana yang dimasukkan sesuai permintaan paket. Urutan awal: masukkan DVD-3 dengan perintah <apt-cdrom add>. Lalu jalankan apt-get update. Kemudian instal Apache2 dengan apt-get install -y apache2. Saat instalasi memunculkan permintaan media, instruksi menekankan penggunaan menu Devices &gt; Optical Drives untuk memilih ISO yang sesuai (misalnya debian-10.5.0-i386-DVD-3.iso, kemudian Binary-1, Binary-2, Binary-3). Tutor juga perlu mengajarkan tindakan Force Unmount dan menekan Enter setelah memilih drive agar proses instalasi lanjut.

Kemudian materi menginstruksikan instalasi MySQL dengan apt-get install -y mysql* sebagai aplikasi basis data. Pada tahap ini, materi juga menegaskan perlunya pergantian DVD saat diminta. Setelah itu instal PHP dengan apt-get install -y php7.3*. Bila muncul masalah paket broken, gunakan apt --fix-broken install dan ikuti konfirmasi (misalnya menekan Y). Lalu, instal paket tambahan PHP: php7.3-zip dan php7.3-curl. Materi menyebut bahwa paket ini merupakan pendukung aplikasi tertentu (contohnya Opencart) sehingga tidak selalu wajib, namun berguna jika akan membuat/ membangun konten web toko online.

Berikutnya, materi mengatur akses remote. Tutor perlu menekankan bahwa agar bisa menggunakan aplikasi seperti WinSCP, PuTTY, dan FileZilla untuk pengelolaan file, SSH harus mengizinkan root login. Caranya: edit /etc/ssh/sshd_config menggunakan nano, cari baris #PermitRootLogin prohibit-password, ubah menjadi PermitRootLogin yes (hapus tanda pagar #), lalu simpan dan restart SSH dengan /etc/init.d/ssh restart. Tutor harus menekankan pentingnya memastikan hasil restart OK sebelum melanjutkan.

Setelah SSH siap, tutor memandu pengunggahan phpMyAdmin. Materi menginstruksikan membuka WinSCP, mengisi Hostname (IP WAN atau nama domain), user root, dan password root. Setelah login, lakukan copy phpMyAdmin dari sisi client ke server pada /var/www/html. Tutor juga harus menekankan bahwa file phpMyAdmin perlu sudah disiapkan di komputer sebelum dicopy.

Setelah file phpMyAdmin berada di folder /var/www/html, materi memandu instalasi unzip (apt-get install -y unzip) agar file dapat diekstrak. Tutor mengajarkan pindah direktori cd /var/www/html, lalu menjalankan unzip php dengan memanfaatkan tombol Tab agar nama file lengkap terdeteksi. Setelah unzip selesai, ubah nama folder hasil ekstraksi dari phpMyAdmin-5.0.2-all-languages menjadi phpmyadmin menggunakan mv. Lalu berikan izin akses dengan chmod 755 -R /var/www/html/phpmyadmin agar web server dapat mengakses folder tersebut.

Materi juga menjelaskan pengaturan password untuk akun root MySQL: mysqladmin -u root password 12345678, lalu restart MySQL (/etc/init.d/mysql restart) dan pastikan OK. Selanjutnya, untuk verifikasi port yang aktif, materi menambahkan instalasi nmap (apt-get install -y nmap) lalu menjalankan nmap localhost. Tutor perlu menegaskan port yang harus terdaftar: http port 80 untuk Apache2 dan mysql port 336 untuk MySQL (sesuai materi). Pengecekan port ini membantu memastikan layanan berjalan.

Tahap akhir adalah verifikasi melalui browser. Tutor perlu memastikan pengguna membuka nama domain (contoh tkjclub.info) untuk melihat halaman default “Apache2 Debian Default Page”. Lalu pengguna membuka tab baru dengan nama domain/phpmyadmin untuk menampilkan halaman login phpMyAdmin. Jika tampil form login, pengguna login menggunakan Username root dan Password 12345678. Jika berhasil masuk dan tampilan phpMyAdmin database muncul, maka konfigurasi web server (Apache2 + PHP + MySQL + phpMyAdmin) dinyatakan selesai.
