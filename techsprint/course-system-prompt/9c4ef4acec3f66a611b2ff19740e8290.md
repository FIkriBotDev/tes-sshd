Materi utama:
Python adalah bahasa pemrograman tingkat tinggi yang dirancang agar mudah dibaca dan dipelajari. Diciptakan oleh Guido van Rossum pada tahun 1991, Python kini banyak digunakan di bidang Data Science, AI, dan pengembangan web. Keunggulannya meliputi sintaks yang sederhana, komunitas besar, pustaka (library) yang lengkap, serta dukungan multi-platform seperti Windows, Mac, dan Linux.

Materi dasar mencakup konsep variabel dan tipe data (integer, float, string, boolean), operator aritmatika dan perpangkatan, serta struktur kontrol seperti percabangan (if, elif, else). Selain itu, materi membahas perulangan dengan for dan while, struktur data untuk koleksi (list, tuple, dictionary), serta fungsi (function) untuk membuat kode yang dapat dipanggil kembali. Semua konsep tersebut menjadi fondasi penting sebelum mempelajari library populer seperti NumPy, Pandas, dan Django.

Materi membahas dasar-dasar pemrograman Python sebagai fondasi untuk pengembangan keterampilan hingga masuk ke library dan domain lanjutan seperti Data Science, AI, dan web. Tutor sebaiknya menekankan bahwa Python adalah bahasa tingkat tinggi yang dirancang agar mudah dipahami. Poin historis (Guido van Rossum, 1991) bisa digunakan untuk memberi konteks mengapa Python berkembang luas. Keunggulan praktisnya mencakup sintaksis yang sederhana dan mirip bahasa Inggris, dukungan ekosistem melalui komunitas dan library yang lengkap, serta kemampuan berjalan di berbagai sistem operasi (Windows, Mac, Linux). Dengan pemahaman ini, peserta diharapkan termotivasi karena Python “ramah pemula” dan tetap relevan untuk banyak kebutuhan teknis.

Bab variabel dan tipe data menjelaskan bahwa variabel adalah wadah penyimpanan data. Hal penting yang perlu dipahami tutor: Python tidak meminta deklarasi tipe data secara eksplisit seperti beberapa bahasa lain. Tutor dapat memberi contoh deklarasi variabel: nama sebagai string, umur sebagai integer, tinggi sebagai float, serta is_student sebagai boolean. Dari materi, tipe data dasar yang harus dikuasai adalah Integer (bilangan bulat, contoh 10 dan -5), Float (desimal, contoh 3.14 dan 2.0), String (teks diapit kutip, contoh "Halo Dunia"), dan Boolean (True atau False). Tutor perlu menegaskan efek praktis tipe data terhadap operasi: integer untuk hitungan bulat, float untuk angka desimal, string untuk teks, dan boolean untuk keputusan (kondisi percabangan).

Bagian operator membahas fungsi operator terhadap nilai/variabel. Tutor dapat mengaitkan penggunaan operator dengan kebutuhan membuat logika dan perhitungan. Operator yang muncul pada materi mencakup: + untuk penjumlahan (misal 5 + 2 = 7), - untuk pengurangan (5 - 2 = 3), * untuk perkalian (5 * 2 = 10), / untuk pembagian (5 / 2 = 2.5), serta ** untuk perpangkatan (5 ** 2 = 25). Selain menjelaskan arti tiap operator, tutor perlu menekankan bahwa pemahaman operator memengaruhi hasil numerik, termasuk pembagian yang menghasilkan float (2.5).

Struktur kontrol percabangan (if, elif, else) digunakan untuk membuat keputusan berdasarkan kondisi. Materi memberi contoh menentukan grade berdasarkan nilai: if nilai >= 90 menghasilkan Grade: A; elif nilai >= 75 menghasilkan Grade: B; else menghasilkan Grade: C. Tutor perlu menekankan pola evaluasi berurutan: program akan memeriksa kondisi dari atas ke bawah dan mengambil blok pertama yang memenuhi syarat. Ini membantu peserta memahami bagaimana membangun aturan logika di program.

Perulangan (loops) terdiri dari for dan while. For loop pada materi menggunakan range(5) untuk iterasi sejumlah tertentu, lalu mencetak iterasi. Tutor bisa menekankan bahwa variabel i mengambil nilai dari rentang tersebut. Sedangkan while loop memeriksa kondisi sebelum setiap iterasi. Contoh materi menggunakan count = 0, lalu while count < 3 mencetak "Halo!" dan menaikkan count dengan count += 1. Tutor sebaiknya menekankan pentingnya update variabel dalam while agar tidak terjadi loop tak berujung.

Struktur data list, tuple, dan dictionary memperkenalkan cara menyimpan sekumpulan data. List bersifat terurut dan dapat diubah; tutor bisa mencontohkan bahwa list cocok untuk data yang akan berubah (misalnya menambah atau menghapus elemen). Tuple juga terurut tetapi tidak bisa diubah; ini cocok untuk data yang sifatnya tetap. Dictionary menyimpan key-value sehingga tutor perlu menjelaskan kegunaan akses berdasarkan kunci, bukan berdasarkan posisi saja. Contoh user = {"nama": "Andi", "usia": 25} dapat dipakai untuk menekankan bahwa key berfungsi sebagai identitas data.

Terakhir, materi memperkenalkan fungsi. Fungsi adalah blok kode yang berjalan hanya saat dipanggil, sehingga membantu modularitas. Contoh fungsi sapa(nama) mengembalikan string sapaan menggunakan f-string. Tutor dapat mengaitkan manfaat fungsi: mengurangi pengulangan kode, meningkatkan keterbacaan, dan memudahkan pengujian. Setelah fondasi ini, materi menutup dengan arah belajar lanjutan: menggunakan library seperti NumPy untuk matematika, Pandas untuk pengolahan data, dan Django untuk pengembangan web.
