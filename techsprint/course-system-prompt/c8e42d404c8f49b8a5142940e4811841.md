Materi course ini:
Di course ini kamu belajar SQL dari nol: konsep dasar, perintah SELECT untuk menampilkan data, manipulasi (INSERT/UPDATE/DELETE), filtering dengan WHERE, pengurutan, lalu masuk ke fungsi-fungsi SQL dan sub-query. Bonusnya, kamu juga dapat pemahaman singkat tentang batasan hak cipta (yang sering muncul di materi/produk belajar).

Materi pada PDF membahas “Pengenalan Dasar SQL” dari sisi konsep dan kemampuan praktis query. Di bagian awal, buku menempatkan SQL sebagai bahasa untuk mengakses dan mengolah data di database. Kamu diperkenalkan bahwa SQL tidak hanya untuk menampilkan data, tetapi juga untuk melakukan interaksi seperti pembatasan (filtering) dan pengurutan, manipulasi data, penggunaan fungsi (termasuk fungsi yang bekerja pada satu baris dan fungsi grup), serta penggunaan sub-query dan operator set. Karena PDF memuat juga daftar isi yang luas, tutor sebaiknya membimbing siswa secara bertahap sesuai struktur bagian: Bagian 1 tentang pembatasan dan pengurutan data; Bagian 2 tentang interaksi dengan SQL termasuk SELECT dan manipulasi data; Bagian 3 tentang seleksi data dengan WHERE serta pengurutan data; Bagian 4 tentang fungsi-fungsi SQL; Bagian 5 tentang penggunaan sub query. Pada Bagian 2, kamu menampilkan data dengan perintah SELECT. Tutor bisa jelaskan kapabilitas SELECT: memilih semua kolom atau sebagian kolom, menulis query secara benar, menambahkan ekspresi aritmatik pada kolom hasil, mendefinisikan nilai NULL sebagai bagian dari output atau logika, menggunakan kolom alias agar hasil mudah dibaca, memakai operator concat untuk menggabungkan string, menggunakan karakter literal string (misalnya teks di dalam tanda kutip), dan memahami operator quote (q) bila didukung engine tertentu. Selain itu, siswa juga dikenalkan konsep duplikasi baris (misalnya perilaku SELECT DISTINCT vs default) dan cara menampilkan struktur tabel (biasanya melalui perintah khusus/metadata tergantung DBMS). Lalu pada Bagian 2 bagian manipulasi data, tutor perlu memastikan siswa paham perintah DML: INSERT untuk menambah baris, UPDATE untuk mengubah baris yang memenuhi kondisi, dan DELETE untuk menghapus baris. Pesan penting yang bisa ditekankan: UPDATE dan DELETE sebaiknya memakai WHERE agar tidak mengubah/menghapus seluruh tabel tanpa sadar. Pada Bagian 3, fokus meningkat pada seleksi data dengan klausa WHERE. Tutor jelaskan bahwa WHERE menjadi pusat pengontrolan baris yang tampil. Operator pembanding meliputi BETWEEN untuk rentang, IN untuk memilih nilai dari daftar, LIKE untuk pola string (menggunakan wildcard seperti % atau _), serta penanganan NULL. Bagian ini juga membahas operator logical AND, OR, dan NOT. Tutor harus menekankan prioritas operator: bagaimana AND dan OR dievaluasi, serta kapan sebaiknya gunakan tanda kurung agar maksud query jelas. Setelah filtering, siswa belajar pengurutan data dengan konsep ORDER BY. PDF menyebut urutan DESC (descending), mengurutkan dengan kolom alias, mengurutkan berdasarkan nomor kolom, dan mengurutkan beberapa kolom sekaligus. Artinya, tutor perlu membuat siswa memahami bahwa urutan sortir bersifat bertingkat: kolom pertama menentukan utama, lalu jika seri baru kolom kedua, dan seterusnya. Bagian 4 memperluas kemampuan dengan fungsi-fungsi SQL. Tutor perlu memetakan fungsi ke dua kategori besar: Single-row functions dan Multiple-row functions. Single-row functions bekerja pada setiap baris secara independen: (1) Fungsi karakter seperti LOWER, UPPER, INITCAP, serta manipulasi karakter seperti CONCAT, SUBSTR, LENGTH, INSTR, LPAD/RPAD, TRIM, REPLACE. (2) Fungsi angka seperti ROUND, TRUNC, MOD. (3) Fungsi tanggal seperti MONTHS_BETWEEN, ADD_MONTHS, NEXT_DAY, LAST_DAY, serta aspek ROUND/TRUNC untuk pengolahan tertentu. (4) Fungsi konversi seperti TO_CHAR, TO_NUMBER, TO_DATE. (5) Fungsi nested (fungsi di dalam fungsi). (6) Fungsi umum lainnya seperti NVL, NVL2, NULL IF, COALESCE, dan kondisi ekspresi. Untuk fungsi grup (agregasi), tutor menjelaskan AVG dan SUM pada tipe data angka; MIN dan MAX untuk angka/karakter/tanggal; COUNT untuk menghitung jumlah baris; bagaimana fungsi grup berinteraksi dengan NULL; klausa grup (misalnya ide GROUP BY); serta konsep fungsi grup nested (bersarang) bila ada. Pada akhir Bagian 4, PDF membahas Multiple-row functions yang berkaitan dengan join antar tabel: natural join (dengan USING dan ON), self join, nonequi join, dan outer join (left/right/full). Tutor perlu menekankan perbedaan inner join vs outer join: outer join menjaga baris tetap tampil meskipun pasangan tidak ada. Lalu dibahas juga Cartesian Products yang merupakan hasil kombinasi semua kemungkinan pasangan baris (biasanya berisiko menghasilkan hasil sangat besar bila tidak disaring). Bagian 5 membahas penggunaan sub-query. Tutor perlu membimbing konsep bahwa sub-query adalah query di dalam query, dipakai untuk menghasilkan nilai atau daftar yang digunakan pada query utama. PDF menyebut macam sub-query: single-row operation dan multiple-row operation. Tutor bisa memberi contoh umum pola IN (SELECT ...) untuk multiple-row dan operator pembanding langsung untuk single-row. Selain itu, PDF juga menyebut operator set, yang secara konsep membantu membandingkan himpunan hasil query (misalnya gabungan/irisan/perbedaan tergantung DBMS), jadi tutor harus mengaitkan ke pola “hasil query adalah himpunan” bukan sekadar list biasa. Terakhir, bagian awal PDF memuat materi UU No 28 tahun 2014 tentang Hak Cipta: menegaskan bahwa hak cipta adalah hak eksklusif yang terdiri atas hak moral dan hak ekonomi. PDF juga menyebut pembatasan perlindungan dalam situasi tertentu seperti kutipan singkat untuk pelaporan peristiwa aktual, penggandaan untuk penelitian, penggandaan untuk pengajaran (dengan pengecualian pertunjukan dan fonogram yang telah diumumkan sebagai bahan ajar), serta penggunaan untuk pendidikan dan pengembangan ilmu pengetahuan yang memungkinkan suatu ciptaan dapat digunakan tanpa izin pihak-pihak tertentu. Tutor sebaiknya menyisipkan pengingat etika: siswa boleh belajar dan mengutip seperlunya untuk konteks pendidikan, namun tidak boleh melakukan pelanggaran hak ekonomi untuk penggunaan komersial yang dapat dikenai sanksi pidana dan/atau denda sesuai Pasal 113. Dengan cara ini tutor menggabungkan literasi teknis SQL (SELECT/WHERE/ORDER BY/fungsi/join/subquery) dan literasi aturan hak cipta agar aktivitas belajar tetap aman dan bertanggung jawab.
