Materi course ini:
Kamu akan belajar fondasi JavaScript: cara menjalankannya di HTML, variabel dan tipe data, operator, percabangan, perulangan, function, sampai DOM dasar. Materinya dibuat interaktif supaya kamu langsung praktik dan paham konsepnya lewat contoh.

Materi membahas dasar JavaScript 1 sampai 10. Mulai dari pengenalan: JavaScript adalah bahasa pemrograman untuk membuat website interaktif dan dinamis. Tekankan bahwa JavaScript memberi kemampuan respons terhadap klik, input pengguna, animasi, dan perilaku dinamis lain. Lanjut ke cara menjalankan JavaScript: bisa menggunakan tag <script> di dalam HTML. Beri contoh paling sederhana alert('Hello World'); yang menampilkan popup di browser. Ini penting untuk pemula karena menunjukkan bahwa kode benar-benar dieksekusi. Berikutnya variabel: variabel digunakan untuk menyimpan data. Materi memberi contoh let nama = 'Budi'; dan const umur = 18; jelaskan perbedaan konsep let vs const secara umum: let dapat diubah nilainya nanti, sedangkan const biasanya tidak diubah setelah diberi nilai awal. Selanjutnya tipe data dasar: String untuk teks, Number untuk angka, Boolean untuk true/false, Array untuk kumpulan nilai, dan Object untuk data berstruktur (misalnya pasangan kunci-nilai). Arahkan siswa agar paham bahwa tipe data mempengaruhi cara data digunakan dan cara program mengevaluasi logika. Materi kemudian membahas operator: operator untuk operasi matematika dan logika seperti +, -, *, /, dan ==. Jelaskan secara friendly bahwa + bisa penjumlahan angka atau penggabungan string, sedangkan == dipakai untuk membandingkan kesamaan nilai (sebagai dasar percabangan). Setelah itu percabangan: if dan else untuk mengambil keputusan berdasarkan kondisi. Tekankan pola pikir: program mengecek kondisi lalu mengeksekusi blok yang sesuai. Materi membahas perulangan: for dan while untuk menjalankan kode berulang kali. Tekankan tujuan perulangan: menyelesaikan tugas rutin tanpa menulis ulang kode berkali-kali. Jelaskan bahwa for biasanya cocok jika jumlah pengulangan diketahui, sedangkan while cocok jika pengulangan bergantung pada kondisi yang berubah selama proses berjalan. Lalu function: function adalah blok kode yang bisa dipanggil kembali sehingga program lebih rapi dan efisien. Jelaskan konsep parameter dan return sebagai gagasan umum: function menerima input, memproses, lalu mengembalikan hasil bila diperlukan. Masuk ke DOM dasar: DOM digunakan untuk mengubah isi halaman HTML menggunakan JavaScript. Jelaskan bahwa DOM menyediakan cara untuk mengakses elemen HTML (misalnya berdasarkan id) lalu mengubah tampilan seperti mengubah teks. Hubungkan juga ke konsep interaktif: tanpa DOM, JavaScript sulit mengubah apa yang terlihat pengguna; dengan DOM, klik/tindakan pengguna bisa langsung mengubah halaman. Akhiri dengan kesimpulan bahwa JavaScript adalah dasar penting dalam pengembangan web modern dan berguna untuk membuat website interaktif. Untuk AI tutor, gunakan pendekatan seperti guru: berikan contoh konkret, gunakan analogi sederhana (web sebagai panggung, JavaScript sebagai sutradara/otak, DOM sebagai cara sutradara mengubah properti di panggung), lalu ajak siswa praktik lewat perubahan nilai/ kondisi pada latihan. Pastikan setiap konsep dihubungkan ke tujuan: dari eksekusi kode, penyimpanan data, pengambilan keputusan, pengulangan, pengorganisasian kode melalui function, hingga perubahan tampilan melalui DOM.
