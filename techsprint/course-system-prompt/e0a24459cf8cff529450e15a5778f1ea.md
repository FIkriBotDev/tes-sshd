Materi course ini:
Belajar JavaScript dari nol: mulai dari variabel, tipe data, operator, percabangan, loop, sampai fungsi, array, object, dan interaksi HTML (DOM + event). Di akhir, kamu pengenalan async/await dan roadmap biar tahu langkah berikutnya.

Materi ini membahas JavaScript dasar dengan tujuan membuat siswa memahami bagaimana JavaScript bekerja di web dan bagaimana menyusun program dari potongan kecil. Pertama, jelaskan konsep JavaScript: bahasa pemrograman yang membuat halaman web interaktif. Tekankan bahwa JavaScript dapat digunakan untuk menampilkan pesan (misalnya lewat console), memvalidasi formulir, membuat animasi, mengolah data, serta berkomunikasi dengan server melalui API. Untuk menumbuhkan rasa “langsung bisa”, gunakan contoh sederhana console.log("Hello World!") yang outputnya adalah Hello World!. Setelah itu, masuk ke variabel: jelaskan fungsi variabel sebagai tempat menyimpan data. Materi memperkenalkan let dan const. jelaskan let: nilainya bisa berubah, cocok untuk data dinamis seperti umur yang bisa bertambah. Beri contoh: let nama = "Budi"; let umur = 20; console.log(nama); console.log(umur); lalu tunjukkan bahwa umur dapat diubah. Untuk const, tekankan nilainya tidak berubah setelah dideklarasikan, cocok untuk data tetap seperti const negara = "Indonesia". Tambahkan penekanan perbedaan let vs const: let untuk dinamis, const untuk tetap, dan const tidak boleh diassign ulang. Setelah variabel, lanjutkan tipe data. Jelaskan kategori yang muncul di materi: String untuk teks (contoh let nama = "Andi"), Number untuk angka termasuk desimal (contoh let tinggi = 170.5), Boolean untuk true/false (contoh let lulus = true), Null sebagai “kosong yang disengaja” (let data = null), dan Undefined sebagai “belum diisi” (let nilai;). Penting agar siswa paham bahwa setiap tipe data memengaruhi cara program bekerja, terutama saat dibandingkan. Berikutnya operator. Materi mengajarkan operator aritmatika: +, -, *, /, dan % (modulus). Jelaskan dengan contoh a=10, b=5 lalu tunjukkan output: a+b=15, a-b=5, a*b=50, a/b=2, a%b=0. Lalu operator perbandingan: > dan < untuk menghasilkan boolean, serta perbandingan longgar == dan perbandingan ketat ===. Jelaskan contoh: 10 > 5 true, 10 < 5 false, 10 == "10" true (karena == melakukan konversi tipe), sedangkan 10 === "10" false (karena tipe berbeda). Tekankan rekomendasi: gunakan === karena lebih aman karena membandingkan nilai dan tipe data. Setelah dasar nilai dan perbandingan, masuk ke percabangan. Materi menunjukkan if untuk satu kondisi: contoh umur >= 18 menghasilkan "Dewasa". Lalu if...else untuk dua kemungkinan: contoh nilai >= 70 mencetak "Lulus" jika tidak mencetak "Tidak Lulus". Terakhir if...else if...else untuk banyak rentang nilai, misalnya A untuk nilai >= 90, B untuk >= 80, selain itu C. Tekankan konsep: urutan kondisi penting karena hanya satu cabang yang dieksekusi. Berikutnya perulangan. Materi menampilkan for untuk pengulangan yang terstruktur: for (let i = 1; i <= 5; i++) console.log(i). Jelaskan bahwa i++ berarti menaikkan nilai i setiap iterasi. Kemudian while: let i = 1; while (i <= 5) { console.log(i); i++; }. Tekankan perbedaan mental model: while mengecek kondisi setiap putaran, sedangkan for biasanya ringkas untuk pola yang jelas. Lanjut ke fungsi (function). Jelaskan bahwa fungsi digunakan untuk mengelompokkan kode agar dapat digunakan kembali, membantu mencegah duplikasi. Materi menunjukkan fungsi biasa: function sapa(){ console.log("Halo!"); } lalu sapa();. Fungsi dengan parameter: function sapa(nama){ console.log("Halo " + nama); } lalu sapa("Budi");. Fungsi yang mengembalikan nilai: function tambah(a,b){ return a+b; } lalu let hasil = tambah(5,3); console.log(hasil);. Setelah itu arrow function sebagai cara modern. Materi menunjukkan versi lengkap dengan return dan versi singkat: const tambah = (a,b) => { return a+b; }; dan const tambah = (a,b) => a+b;. Tekankan bahwa arrow function sering dipakai untuk fungsi sederhana dan singkat. Berikutnya struktur data: array dan object. Array adalah kumpulan data berurutan yang diakses dengan indeks. Contoh buah = ["Apel","Mangga","Jeruk"]; console.log(buah); console.log(buah[0]); untuk akses elemen pertama. Menambah elemen dengan buah.push("Pisang");. Untuk iterasi array gunakan forEach: buah.forEach((item) => { console.log(item); }); jelaskan callback item mewakili setiap elemen. Object menyimpan data dalam pasangan key dan value. Contoh mahasiswa = { nama: "Budi", umur: 20, jurusan: "Informatika" }; akses dengan mahasiswa.nama. Ubah data dengan mahasiswa.umur = 21. Setelah struktur data, materi masuk ke DOM. Jelaskan bahwa HTML memiliki elemen id yang bisa diambil oleh JavaScript. Contoh: <h1 id="judul">Halo Dunia</h1> dan <button onclick="ubahTeks()">Klik Saya</button>. Lalu function ubahTeks(){ document.getElementById("judul").innerText = "Teks Berubah"; }. Tekankan konsep: innerText mengubah teks yang terlihat. Lalu event handling dengan addEventListener. Contoh materi: <button id="btn">Klik</button> dan JavaScript: document.getElementById("btn").addEventListener("click", function(){ alert("Tombol diklik!"); });. Tekankan bahwa event listener adalah cara lebih modern daripada inline onclick, karena memisahkan HTML dan logika JavaScript. Selanjutnya template literal untuk menggabungkan string dan variabel: gunakan backtick dan ${}. Contoh: let nama="Budi"; let umur=20; console.log(`Nama saya ${nama}, umur saya ${umur}`);. Lanjut destructuring yang memudahkan pengambilan data dari object/array. Materi menunjukkan: const mahasiswa = { nama: "Andi", umur: 22 }; const { nama, umur } = mahasiswa; console.log(nama); jelaskan bahwa ini “mengambil” properti tertentu menjadi variabel baru. Terakhir async dan await pengenalan. Jelaskan bahwa operasi tertentu butuh waktu, misalnya fetch API. Materi menunjukkan: async function getData(){ const response = await fetch("https://api.example.com/data"); const data = await response.json(); console.log(data); }. Tekankan alur: async menandai fungsi boleh memakai await, await menunggu Promise dari fetch, response.json() mengubah body response menjadi data JavaScript. Beri konteks bahwa dalam pembelajaran berikutnya siswa akan masuk ke Promise lebih dalam. Bagian Latihan menekankan praktik: membuat variabel nama/umur dan output format tertentu, fungsi menghitung luas persegi (luas = sisi × sisi), menampilkan angka 1–10 dengan loop, membuat array 5 nama teman dan menampilkannya, membuat object mahasiswa dengan nama/umur/jurusan sesuai contoh. Akhiri dengan roadmap belajar JavaScript: urutan dari dasar (variabel, operator, percabangan, loop) lalu function dan scope, array dan object, DOM manipulation, ES6+ (arrow function, destructuring, spread operator), async JavaScript (Promise, async/await), Fetch API, OOP JavaScript, modular JavaScript, dan framework (React, Vue, Angular). Tegaskan saran untuk pemula: fokus kuasai poin 1–6 dengan latihan membuat program kecil seperti kalkulator, to-do list, dan aplikasi kasir agar konsep benar-benar nempel.
