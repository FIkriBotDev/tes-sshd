Course Konfigurasi Web Server Apache2, MySQL, dan phpMyAdmin pada Debian

Web server adalah software yang memberikan layanan berbasis data dengan menerima permintaan HTTP dari client. Pada konfigurasi ini, web server bertugas mentransfer berkas (teks, gambar, video, dll.) melalui protokol HTTP/HTTPS agar konten web dapat diakses oleh pengguna lewat browser.

Chapter 1: Pengertian, Fungsi, dan Perbedaan HTTP vs HTTPS

Web Server adalah software yang memberikan layanan berbasis data dan berfungsi menerima permintaan HTTP (HyperText Transfer Protocol) dari client yang dikenali.

Web server berfungsi untuk mentransfer data atau berkas atas permintaan client melalui HTTP/HTTPS. Di dalam sebuah web, terdapat berbagai jenis berkas seperti text, gambar, video, dan sebagainya, sehingga server perlu mengirimkannya kembali sesuai permintaan.

Perbedaan mendasar antara HTTP dan HTTPS yaitu: HTTP merupakan protokol jaringan/aplikasi untuk sistem informasi terdistribusi. Sedangkan HTTPS adalah protokol yang sama dengan HTTP, namun menggunakan sistem pengaman (secure) agar komunikasi lebih aman.

Chapter 2: Persiapan dan Langkah Konfigurasi Awal (Routing/DNS, DVD, Update, Apache2)

Langkah awal konfigurasi web server adalah memastikan konfigurasi Router Server dan DNS Server telah selesai serta berhasil. Pastikan domain yang akan dipakai (misalnya nama domain) dapat mengarah ke server.

Setelah persiapan jaringan siap, masukkan media instalasi DVD-3 Debian terlebih dahulu. Gunakan perintah apt-cdrom add lalu masukkan DVD-3, kemudian jalankan apt-get update untuk memperbarui daftar paket.

Selanjutnya instal aplikasi web server yaitu Apache2 dengan perintah: apt-get install -y apache2. Pada proses instalasi, bila diminta memasukkan DVD tertentu (misalnya DVD Binary-1/Binary-2/Binary-3), ikuti sesuai permintaan dan gunakan menu Devices > Optical Drives untuk memilih file ISO yang sesuai, lalu lakukan Force Unmount bila diperlukan.

Chapter 3: Instal MySQL, PHP, Paket Pendukung, dan Pengaturan Akses Remote (SSH/WinSCP)

Setelah Apache2 terpasang, lanjutkan instalasi MySQL sebagai aplikasi basis data dengan perintah apt-get install -y mysql*. Pada tahap ini, saat muncul kebutuhan penggantian media instalasi, masukkan DVD Binary-2 melalui Devices > Optical Drives, lalu lakukan proses unmount/enter sesuai instruksi yang tampil.

Selanjutnya instal PHP dengan perintah apt-get install -y php7.3*. Jika terjadi broken pada paket, jalankan apt --fix-broken install. Untuk dukungan tambahan, instal paket PHP pendukung seperti php7.3-zip dan php7.3-curl menggunakan perintah apt-get install -y php7.3-zip php7.3-curl (disebut sebagai paket pendukung, misalnya untuk kebutuhan aplikasi seperti Opencart).

Untuk akses remote menggunakan aplikasi seperti WinSCP, PuTTY, FileZilla, edit konfigurasi SSH dengan perintah nano /etc/ssh/sshd_config. Cari #PermitRootLogin prohibit-password, lalu ubah menjadi PermitRootLogin yes (pastikan menghapus tanda pagar #), simpan dengan Ctrl + X, tekan Y, lalu Enter. Restart SSH menggunakan /etc/init.d/ssh restart, pastikan hasilnya OK, lalu login ke server melalui WinSCP dengan Hostname (IP WAN/Nama Domain), user root, dan password sesuai yang digunakan.

Chapter 4: Upload phpMyAdmin, Unzip, Konfigurasi Permission, User Admin, Restart MySQL, dan Verifikasi Port & Akses Browser

Setelah login WinSCP berhasil, salin folder/file phpMyAdmin ke direktori Linux pada /var/www/html. Di sisi WinSCP, pastikan memilih partisi/folder yang benar (bagian Linux) lalu lakukan copy hingga selesai. Setelah itu, install paket unzip agar file phpMyAdmin dapat diekstrak dengan perintah apt-get install -y unzip.

Pindah ke folder /var/www/html menggunakan perintah cd /var/www/html, lalu lakukan ekstraksi phpMyAdmin dengan perintah unzip php (menggunakan Tab untuk melengkapi nama file). Setelah proses unzip selesai, ganti nama folder phpMyAdmin-5.0.2-all-languages menjadi phpmyadmin menggunakan mv phpMyAdmin-5.0.2-all-languages phpmyadmin. Berikan izin akses dengan chmod 755 -R /var/www/html/phpmyadmin.

Selanjutnya buat user/admin untuk login phpMyAdmin dengan perintah mysqladmin -u root password 12345678, lalu restart MySQL menggunakan /etc/init.d/mysql restart (pastikan hasil OK). Untuk pengecekan port aplikasi yang aktif, instal nmap dengan apt-get install -y nmap dan cek port menggunakan nmap localhost. Pastikan port yang terdaftar sesuai: http port 80 (Apache2) dan mysql port 336 (MySQL).

Verifikasi melalui browser: buka URL nama domain (contoh: tkjclub.info) untuk melihat halaman default Apache2, lalu akses nama domain/phpmyadmin untuk menampilkan halaman login phpMyAdmin. Login menggunakan user dan password yang telah dibuat, yaitu Username: root dan Password: 12345678, lalu klik Go. Jika berhasil menampilkan tampilan database phpMyAdmin, berarti konfigurasi WEB Server dan integrasi phpMyAdmin telah selesai.
