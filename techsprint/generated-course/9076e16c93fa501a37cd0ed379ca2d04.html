Panduan Konfigurasi Lab Router & Switch Cisco (Plus Setup AP dan NMS PRTG)

Materi ini menjelaskan panduan praktikum konfigurasi perangkat jaringan Cisco pada sebuah lab yang terdiri dari router, switch, akses point (AP), serta server uji aplikasi. Topologi lab menekankan bahwa nilai “X” menyesuaikan nomor kelompok, router Cisco 1921 bertindak sebagai gateway ke internet, switch Cisco 2960-C digunakan untuk meneruskan beberapa VLAN, AP Wifi mendistribusikan LAN ke client, dan terdapat server web untuk kebutuhan pengujian aplikasi. Materi kemudian membahas cara mengakses perangkat menggunakan kabel USB Console dan terminal emulator seperti PuTTY. Setelah akses CLI berhasil, dilakukan konfigurasi router meliputi hostname, pengaturan username/password/secret, pengaktifan remote telnet via line vty, pengaturan SNMP untuk kebutuhan monitoring NMS, konfigurasi interface WAN (ip nat outside), interface trunk, pembuatan sub-interface VLAN (ip nat inside), routing default, access-list untuk NAT, serta pembuatan NAT pool dan rule NAT. Terakhir, materi mengajarkan penyimpanan konfigurasi dan pengujian koneksi termasuk test ping serta pengecekan NAT. Bagian berikutnya menguraikan konfigurasi switch meliputi hostname, hak akses, telnet, SNMP, setup trunk ke router, setup port akses untuk VLAN server/wifi, pembuatan interface VLAN manajemen agar switch dapat diremote, routing default ke gateway manajemen, serta perintah pengecekan status interface dan penyimpanan konfigurasi. Materi juga mencakup konfigurasi akses point lewat web browser (default IP 192.168.0.254, user/password admin), penyesuaian konfigurasi Wireless, penyelarasan IP AP dengan network gateway router, penentuan DHCP pada AP atau disable bila DHCP sudah ada di Cisco, dan pengaktifan SNMP agent untuk monitoring. Sebagai opsional, materi menjelaskan instalasi server Network Monitoring System (NMS) menggunakan PRTG. Proses mencakup persiapan konektivitas PC ke jaringan, download PRTG dari situs resmi, instalasi dengan mode express, penginputan email, pengelolaan lisensi/trial, hingga penambahan group, device, pembuatan sensor (misalnya ping dan SNMP trafik), serta pembuatan dashboard menggunakan fitur Map untuk memvisualisasikan monitoring.

Chapter 1: Topologi dan Akses Perangkat Lab

Panduan ini digunakan untuk konfigurasi lab router dan switch Cisco. Pada topologi, terdapat beberapa informasi penting: nilai “X” disesuaikan dengan nomor kelompok group lab. Cisco 1921 berfungsi sebagai router/gateway ke internet, sedangkan Cisco 2960-C berfungsi sebagai switch yang meneruskan beberapa VLAN. Terdapat pula AP Wifi untuk distribusi LAN ke client dan Server Web untuk test aplikasi.

Untuk mengakses perangkat Cisco (router atau switch), pengguna dapat menggunakan kabel USB Console. Prosedur umum: hubungkan USB console ke laptop, lalu cek Device Manager untuk mengetahui port COM yang dipakai oleh USB console. Pada contoh materi, USB port berada di COM3.

Setelah port diketahui, akses perangkat menggunakan terminal emulator seperti PuTTY. Bila berhasil, akan tampil Command Line Interface (CLI) Cisco. Dari CLI inilah konfigurasi dilakukan, baik pada mode konfigurasi maupun mode privileged sesuai kebutuhan praktikum.

Chapter 2: Konfigurasi Router Cisco: Identitas, Akses Remote, VLAN, Routing, dan NAT

Konfigurasi router dilakukan dengan memastikan perangkat berada pada mode konfigurasi. Contoh langkah awal: dari prompt router# gunakan perintah configure terminal sehingga masuk ke mode konfigurasi. Lalu atur identitas perangkat dengan hostname sesuai kelompok, misalnya hostname ROUTER-GROUP1.

Selanjutnya lakukan pengaturan kredensial dan proteksi akses. Materi menyertakan contoh pengaturan: username admin privilege 15 password admin123, lalu service password-encryption untuk mengenkripsi kata sandi yang tersimpan pada konfigurasi. Gunakan enable secret admin123 sebagai pengaman mode privileged exec. Materi juga menjelaskan privilege levels di Cisco dari 0 hingga 15 (0 paling rendah, 15 paling tinggi/superuser), serta fungsi masing-masing perintah terkait keamanan.

Agar router dapat diakses via telnet, atur line vty seperti line vty 0 4, lalu gunakan login local, transport input telnet, dan transport output telnet. Materi menjelaskan bahwa line vty 0 4 berarti maksimal ada 5 koneksi bersamaan (0-4), sedangkan kapasitas maksimum dapat diperluas hingga line vty 0 15.

Untuk kebutuhan monitoring oleh NMS, setup SNMP server, misalnya menggunakan community public dengan hak akses RO (Read Only) menggunakan perintah snmp-server community public RO. Kemudian konfigurasi interface WAN: pada contoh GigabitEthernet0/0 aktifkan port dengan no shutdown, berikan deskripsi, set IP, dan tandai sebagai sisi internet dengan ip nat outside.

Untuk penerusan antar perangkat dan VLAN, konfigurasi trunk pada interface GigabitEthernet0/1 dengan deskripsi dan no ip address. Berikutnya buat sub-interface berbasis VLAN untuk setiap kebutuhan LAN: contoh VLAN 10 untuk LAN server, VLAN 20 untuk LAN wifi, dan VLAN 30 untuk LAN manajemen. Setiap sub-interface menggunakan encapsulation dot1Q sesuai VLAN, mengatur description, memberikan ip address, serta menandai sisi LAN sebagai ip nat inside.

Setelah VLAN siap, buat routing default agar semua trafik non-lokal diarahkan ke IP gateway WAN menggunakan ip route 0.0.0.0 0.0.0.0 123.231.1.1 (nama routing dapat diberikan). Lalu buat access-list yang menentukan range IP LAN mana yang diizinkan untuk NAT ke internet, misalnya beberapa permit untuk subnet LAN wifi dan LAN server.

Implementasi NAT dilakukan dengan membuat IP nat pool sesuai IP WAN dan mengaitkan NAT inside source pada access-list. Materi contoh: ip nat pool INTERNET 123.231.1.2 123.231.1.2 netmask 255.255.255.248 lalu ip nat inside source list 1 pool INTERNET overload. Agar static mapping juga berlaku, contoh perintah ip nat outside source static 123.231.1.3 10.10.1.2. Materi juga menyediakan opsi bila ingin NAT hanya port tertentu menggunakan perintah ip nat outside source static tcp (contoh untuk port 443) dengan catatan bahwa jika NAT full sudah dijalankan, perintah opsional ini tidak diperlukan.

Terakhir, jangan lupa menyimpan konfigurasi menggunakan write atau write memory. Lakukan pengujian koneksi: test ping ke gateway dan internet, test koneksi internet dengan source LAN, cek status NAT, serta cek IP yang terkoneksi ke Cisco.

Chapter 3: Konfigurasi Switch Cisco, Access Point, dan Instalasi NMS PRTG (Opsional)

Konfigurasi switch dimulai dari pengaturan identitas dan akses. Materi memberi contoh pengaturan hostname SWITCH-GROUP1, lalu pengaturan username/privilege serta service password-encryption dan enable secret. Setelah itu, aktifkan telnet melalui line vty 0 4 dengan login local serta transport input/output telnet.

Untuk monitoring, setup SNMP dengan contoh community public dan mode RO menggunakan snmp-server community public RO. Lalu atur port trunk ke router pada interface GigabitEthernet0/1: berikan no shutdown, deskripsi TRUNK-ROUTER, tentukan VLAN yang diizinkan dengan switchport trunk allowed vlan 10,20,30, dan set mode switchport mode trunk.

Selanjutnya konfigurasi port akses yang terhubung ke masing-masing LAN. Materi memberi contoh: interface FastEthernet0/1 sebagai PORT-SERVER masuk ke switchport access vlan 10, interface FastEthernet0/2 sebagai PORT-WIFI masuk ke switchport access vlan 20. Pastikan port diaktifkan dengan no shutdown.

Untuk memungkinkan switch diremote, buat VLAN manajemen pada interface Vlan30, aktifkan dengan no shutdown, set deskripsi MANAGEMENT, lalu konfigurasikan IP manajemen dan subnet mask (contoh: ip address 100.100.1.2 255.255.255.248). Tambahkan juga routing default menggunakan ip default-gateway 100.100.1.1. Setelah konfigurasi, simpan dengan write atau write memory dan lakukan pengecekan seperti melihat status IP/interface, deskripsi interface, serta status trunk.

Bagian Konfigurasi Access Point dimulai dengan menghubungkan adaptor (POE) AP: port LAN ke laptop, port POE ke access point. Set IP laptop (contoh 192.168.0.1/24) atau gunakan DHCP otomatis. Akses AP melalui web browser dengan default IP 192.168.0.254, dengan user/password default admin. Jika diminta, ganti password baru. Materi menekankan konfigurasi dimulai dari menu Wireless.

Setelah pengaturan wireless, konfigurasi IP Address AP agar sesuai network gateway router sehingga AP dapat terhubung satu sama lain. Catatan penting: DHCP server diset pada Access Point (AP). Bila DHCP sudah ada di Cisco, maka DHCP pada AP harus disable. Materi juga menyarankan untuk mengaktifkan SNMP agent pada menu Management agar perangkat bisa dimonitor. Setelah itu, lakukan pengetesan koneksi dari wifi client.

Terakhir, Install Server NMS PRTG (Opsional). Materi menggunakan PRTG (Paessler PRTG) sebagai Network Monitoring System. PC/laptop instalasi PRTG harus terkoneksi LAN ke mikrotik port ether2 dan setting IP sesuai alokasi (contoh 10.10.X.2/29). Unduh PRTG dari situs resmi (paessler), kemudian instalasi seperti aplikasi biasa, menerima kebijakan paessler, input email, dan pilih mode instalasi express. Setelah instalasi sukses, cek lisensi pada menu PRTG Status; jika trial berakhir, PRTG masih bisa digunakan terbatas 100 sensor.

PRTG siap memonitor perangkat jaringan/host. Untuk menambahkan monitoring, buka menu Devices, buat group (misalnya “Lab KPTK”), pilih group tersebut lalu tambahkan device seperti router Cisco dengan IP manajemen. Pada device, tambahkan sensor contohnya sensor ping dan sensor SNMP trafik. Untuk tampilan dashboard, gunakan fitur Map dan lihat contoh map yang telah dibuat.
