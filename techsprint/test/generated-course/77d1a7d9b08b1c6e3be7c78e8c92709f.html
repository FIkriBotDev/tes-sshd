Chapter 1: Bab 1: Pengenalan Python & Mengapa Belajar Python

Python adalah bahasa pemrograman tingkat tinggi yang dirancang agar mudah dibaca dan dipelajari. Desainnya menekankan keterbacaan kode sehingga cocok bagi pemula maupun praktisi. Python juga dikenal luas dalam berbagai bidang teknologi, terutama karena fleksibel dan kaya fitur.

Python diciptakan oleh Guido van Rossum pada tahun 1991. Seiring waktu, Python berkembang menjadi salah satu bahasa pemrograman paling populer untuk Ilmu Data (Data Science), Kecerdasan Buatan (AI), dan Pengembangan Web. Hal ini didukung oleh ekosistem library yang besar sehingga banyak kebutuhan pemrograman dapat dipenuhi lebih cepat.

Alasan utama kenapa belajar Python adalah sebagai berikut: sintaksis sederhana yang mirip bahasa Inggris, komunitas besar beserta library yang lengkap, serta kemampuan berjalan di banyak sistem operasi (Windows, Mac, Linux). Dengan bekal dasar yang tepat, kamu bisa membangun proyek-proyek praktis di bidang data, AI, maupun web.

Chapter 2: Bab 2: Variabel, Tipe Data, dan Operator Dasar

Variabel merupakan wadah untuk menyimpan data. Di Python, kamu tidak perlu mendeklarasikan tipe data secara eksplisit, karena Python akan menentukan tipe data berdasarkan nilai yang diberikan. Ini membuat proses penulisan kode lebih cepat dan nyaman bagi pemula.

Tipe data dasar yang dipelajari meliputi: Integer (bilangan bulat), misalnya 10 dan -5; Float (bilangan desimal), misalnya 3.14 dan 2.0; String (teks) yang diapit tanda kutip seperti "Halo Dunia"; serta Boolean yang bernilai logika True atau False.

Contoh variabel yang umum: nama berisi teks, umur berisi bilangan bulat, tinggi berisi bilangan desimal, dan is_student berisi nilai boolean. Untuk menampilkan data secara rapi, kamu bisa menggunakan print bersama format string. Materi juga mengenalkan operator dasar: + untuk penjumlahan, - untuk pengurangan, * untuk perkalian, / untuk pembagian, dan ** untuk perpangkatan.

Dengan memahami tipe data dan operator, kamu bisa mengolah nilai dan menyiapkan data untuk langkah berikutnya seperti pengambilan keputusan dan perulangan.

Chapter 3: Bab 3: Struktur Kontrol, Perulangan, Struktur Data, dan Fungsi

Struktur kontrol digunakan untuk membuat keputusan dalam kode. Python menyediakan if, elif, dan else agar program dapat memilih jalur eksekusi berdasarkan kondisi. Contohnya, nilai ujian dapat diklasifikasikan menjadi grade A, B, atau C menggunakan rangkaian kondisi.

Perulangan (loops) memungkinkan kode dijalankan berulang. Python memiliki dua jenis perulangan utama: for dan while. For loop sering digunakan ketika kamu tahu jumlah iterasi, contohnya iterasi dari 0 sampai 4 menggunakan range(5). While loop cocok ketika kamu ingin perulangan berhenti berdasarkan kondisi tertentu, misalnya selama count kurang dari 3.

Selain kontrol dan perulangan, materi juga membahas struktur data untuk menyimpan koleksi dalam satu variabel. List adalah kumpulan data terurut dan bisa diubah (contoh: buah = ["Apel", "Jeruk"]). Tuple adalah terurut tetapi tidak bisa diubah (contoh: koordinat = (10, 20)). Dictionary berisi pasangan kunci dan nilai (contoh: user = {"nama": "Andi", "usia": 25}).

Terakhir, fungsi (function) adalah blok kode yang hanya berjalan saat dipanggil. Fungsi didefinisikan dengan def. Contoh: fungsi sapa menerima parameter nama lalu mengembalikan string sapaan. Dengan konsep fungsi, kode menjadi lebih terstruktur, mudah digunakan ulang, dan lebih rapi.

Materi penutup menekankan bahwa Python sangat luas. Setelah fondasi ini, langkah selanjutnya adalah mempelajari library seperti NumPy (matematika), Pandas (data), atau Django (web) sesuai tujuanmu.
